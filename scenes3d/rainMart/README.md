# 星降るマート · 雨夜便利店街角微缩模型

三渲二（卡通渲染）风格的雨夜日式便利店街角微缩模型。纯 canvas 全屏渲染，没有任何 UI；
整条街的店铺、道具与建筑全部为真实几何建模，贴图也由 Canvas 2D 在运行时程序化生成，
零外部素材、零网络请求，离线即可运行。

## 运行

三种方式，任选其一：

- **一键启动（推荐）**：双击 `start.bat`。有 Node.js 时会在
  <http://127.0.0.1:4173/> 启动本地服务器并打开浏览器；没有 Node.js 时自动回退到单文件版。
- **单文件离线版**：直接双击 `start.html`。脚本、样式与依赖全部内联，`file://` 下也能运行。
- **手动启动**：`npm start`（等价于 `node serve.mjs`），或在本目录起任意静态服务器。
  源码版使用 ES Module + importmap，需要通过 http 访问，不能直接双击 `index.html`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 环绕旋转 |
| 滚轮 / 双指捏合 | 推进拉远（带最近 / 最远距离限制） |
| 拖拽时 | 光标切换为抓取状态 |
| 调整窗口 | 自动重新取景，并按宽高比调整 FOV |

平移已关闭，镜头只能围绕街角旋转与缩放，方便稳定构图。

## 场景内容

- **便利店**：招牌灯箱与竖招牌、OPEN 灯牌、整面玻璃幕墙（带程序化雨痕与水膜反光）、
  雨棚与门头、地垫、海报、空调外机、屋顶设备与护栏。
- **店内**：货架与成排商品（实例化）、饮料冷柜、杂志架、收银台与 POS 屏、
  关东煮（带蒸汽）、热食柜、咖啡机、烟柜、冰淇淋柜、购物篮、通道吊牌、促销岛与地面导视。
- **街景**：自动贩卖机（成排饮料与按钮）、电线杆 / 电线 / 变压器、路灯、红绿灯、
  自行车、伞架、垃圾桶、护栏、路牌、邮筒、长椅与猫、绿植、后巷服务区、停靠的轻型小货车。
- **邻家与小巷**：带暖帘的街角咖啡店、木檐与灯箱、窄巷、公告栏等细节。
- **天气与地面**：3600 条 GPU 雨丝、檐口滴水与地面水花、水洼涟漪、低空薄雾；
  雨棚与咖啡店深檐下会自动避雨，湿路面反射霓虹与灯光。
- **光影**：四阶 cel ramp 卡通材质 + 描边 + 接触阴影，ACES 色调映射、软阴影与指数雾。

## 实现要点

- **三渲二**：四阶 cel ramp 渐变贴图配合几何描边与接触阴影，在保持卡通色块的同时
  保留雨夜街角的体积感。
- **程序化贴图**：招牌、海报、货架商品、杂志、地砖、玻璃雨痕等全部由 Canvas 2D 绘制，
  仓库里没有任何图片素材。
- **会避雨的雨**：雨丝按店面雨棚与咖啡店屋檐的遮蔽范围跳过，檐口另做滴水与水花。
- **离线优先**：Three.js 与 OrbitControls 已本地化；源码版与单文件版均不发起网络请求。
