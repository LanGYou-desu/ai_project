# 雨夜便利店 · 街角微缩模型

三渲二（卡通渲染）风格的雨夜日式便利店街角微缩模型。纯 canvas 全屏渲染，
无任何 UI 元素；鼠标拖拽旋转 / 滚轮缩放 / 右键（或 Shift+左键）平移视角，
双击复位。全场景为真实几何建模（结构、零件均为几何体，贴图只承载图案信息），
零外部资源、离线可跑（`vendor/three.min.js` 本地 UMD）。

## 运行

```bat
run.bat
```

- 有 Node.js → 起本地静态服务器：<http://127.0.0.1:8137/>（`node serve.js` 亦可）
- 有 Python → 用 `python -m http.server` 起同端口服务
- 都没有 → 直接以 `file://` 打开 `index.html`（离线可用）

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 环绕旋转 |
| 滚轮 / 双指捏合 | 推进拉远 |
| 右键拖拽 / Shift+左键 | 平移（带范围限制） |
| 双击 | 复位视角 |
| 闲置 9 秒 | 缓慢自动环绕 |

## 场景内容

- **便利店**：招牌灯箱（偶发闪烁）、整面玻璃幕、自动感应门（会开合、门缝
  灯外溢）、雨棚与滴水、门口地垫、海报、监控、霓虹灯管、屋顶设备。
- **店内**：货架商品（实例化）、饮料冷柜、便当区、饭团零食、收银台、
  咖啡机、关东煮（带蒸汽）、杂志架、灯箱海报、冰柜、地面导视。
- **街景道具**：贩卖机（真实分格、货道、按钮、退币口）、自行车与停车架、
  伞架、垃圾箱、路灯、电线杆（横担 / 变压器 / 熔断器 / 踏脚钉）、
  电线、路牌、护栏、空调外机、纸箱托盘、公告栏、红绿灯循环、远处霓虹。
- **周边楼房**：11 栋背景建筑全部真实开窗（窗框 / 窗台 / 亮窗暖光 / 暗窗冷灰
  均为几何实例，共 72 扇），混凝土分格缝与雨渍墙体、女儿墙压顶、屋顶水箱 /
  楼梯间 / 排气管 / 天线、雨落管（管卡 / 落水弯头）、电表箱与引下缆、
  两处带门头壁灯与地面光斑的楼门；邻家民居另增南檐沟与西南落水管。
- **天气与地面**：雨丝（GPU 着色）、檐口滴水与涟漪、玻璃雨痕、水膜反光、
  霓虹与车灯湿地倒影、路面标线与人行道盲道、排水沟与井盖。
- **交通信号**：绿 8s → 黄 2.4s → 红 9.5s 循环，灯头亮灭与地面反光同步。

## 目录结构

```
rainMart/
  index.html        入口（9 个脚本按依赖顺序加载，无 UI）
  run.bat           启动脚本
  serve.js          零依赖静态服务器
  vendor/three.min.js   three.js r158 UMD（本地化）
  js/util.js        数学 / 材质 / 几何缓存 / 外扩描边 / 灯光贴图工具
  js/base.js        底座、路面铺装、标线、水洼、排水
  js/store.js       便利店建筑与门面
  js/interior.js    店内陈设
  js/props.js       街景道具
  js/rain.js        雨丝 / 滴水 / 涟漪 / 玻璃雨痕
  js/dynamics.js    动画逻辑（门、招牌、霓虹、信号灯、蒸汽……）
  js/main.js        渲染器 / 相机 / 主循环 / 交互
  test/             Node 无头测试（stub + 断言套件）
```

## 测试

```bat
cd scenes3d/rainMart
node test/run.js
```

`test/stub.js` 用 Proxy 桩掉 canvas 2D / WebGL 上下文，在 Node 里完整加载
真实 `three.min.js` 并构建场景；`test/run.js` 覆盖文件结构、场景装配、
铺装数据、建筑与陈设、雨系统、动态时序、主循环稳定性、相机交互、
视口自适应、构建确定性等1766 项断言。
