# The History Reader · 历史朗读者

把你的浏览器历史变成一首关于今天的小说。

## 是什么

不是分析工具，不是监控软件。这是一个把你的浏览数据转化为文学叙事的装置。

它读取你今天的浏览器历史，找到其中的节奏——寻找、停留、切换、漂移——然后把这些模式写成一段关于你的短篇小说。

## 支持的浏览器

- Google Chrome
- Microsoft Edge（均为 Chromium 内核，数据库结构相同）

## 怎么运行

1. 确保已安装 Chrome 或 Edge
2. 双击 `start.bat`
3. 打开浏览器，访问提示的地址
4. 看一段关于你今天的小说

## 手动运行

```bash
npm install
node server.js
```

然后访问 `http://localhost:8769`

## 上传 JSON

如果浏览器历史不可用，可以先导出为 JSON 格式：

```json
[
  {"url": "https://example.com", "title": "标题", "visitTime": 1690000000000}
]
```

然后在页面上点击"上传 JSON 文件"。

## 原理

- 自动检测 Chrome / Edge 的 SQLite 历史数据库
- 将访问记录按时间分组为"时段"（间隔 > 30 分钟视为不同时段）
- 分析每个时段的行为模式（专注、寻找、漂移、切换）
- 根据模式生成文学叙事

所有数据仅在本地处理，不会上传到任何服务器。
