> **微观生态重建模拟器**：2097 年，苔原星生态崩溃。作为生态方舟的管理员，你从一株苔藓开始，亲手重建从生产者到顶级掠食者的完整食物网，并让它挺过干旱、冰期、陨石与外来物种入侵——整整一百二十年。

## 🎮 怎么玩

1. 主菜单选择 **剧情模式**（6 章，约 1 小时）或 **沙盒模式**（自由演化）。
2. 在左侧选择物种，回到培养皿上 **按住左键涂抹**：
   - 🌿 **植物**：涂抹一次 = 播下一片种子，之后它会自行扩散。
   - 🐾 **动物**：涂抹 = 放生个体。
   - 🧹 **除草 / 🧪 施肥 / 🔍 查看**：三个干预工具。
3. 用顶部 **4× / 8× / 16×** 加速时间，右侧实时观看 **种群动态曲线**——洛特卡-沃尔泰拉式的捕食-猎物波动会自然涌现。
4. 完成章节目标 → 获得 **1~3 星评价** → 解锁新物种与生态学知识卡。

## 🌍 物种系统（21 种）

- **生产者（9）**：苔原苔藓、草原禾草、耐旱灌木、落叶乔木、水生藻类、河岸芦苇、砂原仙人掌、巨型蕨类、外来藤蔓（入侵物种）。
- **消费者（11）**：草间昆虫、草甸田鼠、原野野兔、林间白鹿、长毛猛犸、浅水鲦鱼（食草）；林间织蛛、赤尾狐狸、灰原狼群、巡天苍鹰、巨蜥潜客（捕食）。
- **分解者（1）**：腐生真菌（尸体 → 养分的循环由引擎模拟）。

每种物种拥有独立生态位：地形偏好、温湿度舒适区、代谢率、寿命、繁殖策略（r/K 对策）、食性。物种按章节逐步解锁。

## 🧪 仿真引擎

- **能量流动**：阳光 → 植物生物量 → 食草动物 → 捕食者 → 尸体 → 分解 → 养分 → 植物，能量金字塔自然成形（约 55% 转化效率）。
- **水分/养分/气温**：逐格模拟，季节波动 + 随机气候事件（干旱、热浪、冰期、陨石、瘟疫、丰年、藤蔓入侵）。
- **确定性**：同一种子 + 相同操作序列 → 完全相同的演化，支持「种子 + 操作日志」存档重放与分享。
- **稳定机制**：功能响应（猎物稀缺时捕食成功率下降）、繁殖的猎物/捕食者比例闸门、地形庇护所、残存种群庇护——未管理的生态也会出现真实的暴涨-崩溃-复苏循环，而不会瞬间灭绝。

## 🚀 运行与测试

```bash
# 玩游戏
.\start.bat          # 或直接双击 index.html

# 单元测试（38 项）
node test/run.js

# 开发辅助
node scripts/calibrate.js      # 打印标准场景的种群动态
node scripts/smoke-browser.js  # 浏览器启动冒烟
node scripts/verify-campaign.js # 自动玩家验证 6 章全部可通关
```

> 存档保存在浏览器 localStorage（种子 + 操作日志，可完整重放）。声音为 Web Audio 程序合成，建议佩戴耳机，可在顶栏静音。
