# 天空都市 東京 · TOKYO CELESTIAL METROPOLIS

> 一座**单文件、零依赖、三渲二（Cel-Shaded）**的程序化东京：2,400 m × 2,400 m 的
> 都市在打开页面的几秒内实时生成——数千栋建筑、运河与公园、郊区与远山，
> 白昼 / 黄昏 / 夜三段时刻可一键切换，还有「巡航」模式带你穿过街道。

## 🚀 运行

**方式一（最简单）**：直接双击 `index.html` 即玩（Three.js r159 已内联，无需联网、无需服务）。

**方式二**：双击 `start.bat`（自动用默认浏览器打开）。

## 🎮 操作说明

| 操作 | 效果 |

| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移 |

## 🛠️ 技术栈

- **Three.js r159** 完整内联在 HTML 里，无任何外部请求
- **程序化生成**：道路网 → 街区与建筑群 → 运河 / 公园 → 路灯与电线 → 郊区与山峦，
  带加载进度条；左上角实时显示 建筑数 / 街区数 / FPS
- **三渲二材质**：自定义 toon 着色与描边，白昼 / 黄昏 / 夜三套调色板
- 零运行时依赖，浏览器直接打开即可（需要支持 WebGL）
