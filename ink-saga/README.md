# 墨战 · 天书纪 — INK-SAGA
> **全世界第一款「用笔写字来战斗」的汉字书写战斗史诗。**
>
> 天启七年，纸镇所有的字都醒了。它们化作墨点，吞食活人。你是镇口代写书信的落魄书生陈砚——
> 慌乱中握起那支磨秃的狼毫笔，你发现：**你写的每一个字，都是刀。**

## 🖋️ 核心玩法
- **看目标**：敌人头顶的白牌写着它要的字（「火」「水部」「火海」「火冒三丈」…）
- **写出来**：按住鼠标左键，在屏幕上把这个字写出来，松手判定；右下角有**临摹导引水印**
- **消灭它**：写对即触发字诀——火焚、冰缓、雷链、盾御、愈疗……
- **小心**：敌人走到左侧「纸界」会咬你；写错会断连击；Boss 有守御层，先写「破防字」

### v5 战斗深度与剧情沉浸
- **新敌人·墨傀**：会吸收你写的字——每写对它一次就换一个字，被吞的字化为环绕的墨滴，直到过载崩溃（无尽模式第 2 层起）
- **Boss 专属机制**（每个 Boss 都独一无二）：
  - 成语魇：抛出残句「一鼓作□」，补上最后一字可重创
  - 大书法家：字乱（搅乱所有目标字牌）
  - 甲骨文之灵：字谜（按释义写对应字，破解重创）
  - 墨龙：龙息（限时写「盾」格挡，否则 -15 砚血）
- **剧情场景水墨插图**：每段剧情对话配程序化水墨背景（月下废镇/竹影书院/泽水/铁城/甲骨/龙巢红光）
- **成就奖励**：29 项成就达成即发放文气（30~200），收集成就本身就有回报
- **每日连胜**：连续完成每日一墨，奖励从 +200 逐日 +50 递增
- **无尽层奖励**：每层通关 +10×层数 文气，Boss 层有提示

### v4 氛围与玩法扩展
- **章节主题世界**：每章独立水墨背景与天气——雨夜失字镇、竹影砚山书院、泽水成语之泽、铁城废都、甲骨秘境、墨龙巢红光；雨/雾/落花/疾风/余烬/烟 六种天气粒子
- **章节主题旋律**：明暗两套五声音阶随章节切换（A 羽调暗章 / C 宫调明章）
- **出征纪**：生涯总览——出征次数/累计杀敌/命中率/最高连墨/总文气/收集进度/结局成就 + 按敌人种类的杀敌明细条形图
- **挥毫疾书**：60 秒限时连写模式，超时换字、连墨加分，结算给文气奖励，最佳纪录存档
- **称号系统**：按成就数解锁 无名书生 → 初执笔生 → 习字书生 → 镇字之士 → 墨战宗师 → 承墨天人
- **每日奖励**：完成每日一墨当日首次 +200 文气
- **存档备份**：设置页一键导出存档 JSON 到磁盘 / 从文件导入合并

### v3 深度与留存
- **书法练习场**：自由临摹模式，大号导引水印 + 实时识别判定（连对/最佳/累计），随机选字或从全字库选字，磨笔不误杀敌功
- **Boss 二阶段**：半血触发「墨怒」狂暴——加速、技能更密、红环怒标
- **连击里程碑**：每 10 连击触发增益轮换（笔力激增 / 砚血回涌 / 墨盾护体）
- **每日一墨**：按日期种子生成的确定性挑战（天下同题），5 层连战，每日专属排行榜
- **程序化旋律层**：五声音阶氛围旋律叠加在战斗底噪上，无尽层数越高节奏越快
- **判定详情**：松笔后中央显示你的字与命中判定；设置里可调完美判定阈值

### v2 手感优化
- **识别引擎 v2**：墨迹 1px 膨胀容差 + 长宽比特征 + 四维加权打分（IoU/方向链码/墨量/比例），写得更随意也认得出
- **临摹导引**：右下角实时显示当前最紧急目标字的大号水印，照着描即可
- **判定反馈**：松笔后屏幕中央显示「你写的字 + 命中/未中」；识别不到会提示「你写的是「X」？」
- **打击感**：命中光环扩散、暴击/受伤/Boss 技能震屏、弱点「克X」标签
- **精英变体**：铁甲妖（先写「金」部字破甲）、诅咒妖（先写「暗」部字解咒）、疾影妖（速度极快）
- **波次奖励**：每波清空后的间隙回气 +10~N 文气
- **暂停**：P / Esc / 暂停按钮，战斗中随时休息

## 🎮 内容

## 🚀 快速开始
```powershell
start.bat        # 一键启动（自动打开 http://127.0.0.1:7337）
# 或
node server.js   # 然后浏览器访问 http://127.0.0.1:7337
```

## 🖥️ 超越纯网页的部分
- **Node 后端**（零依赖）：静态服务 + 存档持久化（`save/game.json`）+ 本地排行榜（`save/leaderboard.json`）
- **真实文件导出**：`save/reports/` 汉字体检报告 HTML、`save/exports/` 练习字帖 txt，都是真实磁盘文件
- 浏览器本地（localStorage）与后端文件**双写存档**

## 🧠 技术要点
- **笔迹识别引擎**（`public/js/core/recognition.js`）：轨迹归一化 → 64×64 位图光栅化，与候选字楷体参考图做 **IoU 像素重合 + 8 方向链码直方图 + 墨量密度** 三重特征融合打分；参考图缓存，识别零延迟
- **全程序化美术**：宣纸纹理、水墨粒子、墨块怪物、远山，全部 Canvas 程序生成，零素材
- **全程序化音效**：笔锋过纸、墨点爆开、五声音阶连击、大锣，全部 Web Audio 合成
- **元素系统**：`spells.js` 定义 13 种元素效果与克制关系，接入战斗结算
