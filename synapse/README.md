# SYNAPSE · 神经织造

> **亲手搓一个神经网络，看着它学会思考。**
>
> 不写一行框架代码：在画布上拖拽连线搭网络、调权重、改偏置、换激活函数，然后点「开始训练」——损失曲线当场下降、决策边界在眼前成形。五个数据集从 XOR 一路打到井字棋，训练场里还有五张「毕业证」等着你。

| 项目 | 说明 |
| ---- | ---- |
| 类型 | 神经网络教学沙盒（可视化 + 可交互 + 可训练） |
| 技术栈 | 原生 HTML/CSS/JS + Canvas + Web Audio + Node.js（零第三方依赖） |
| 规模 | 手写反向传播引擎 + 5 个数据集 + 训练场 5 大挑战 + 13 张知识卡 + 权重掩码（稀疏剪枝）+ 存档导入导出 |
| 测试 | node test/run.js（91 项单元测试）+ node test/smoke-ui.js（前端冒烟） |

## 🧠 核心玩法

- **织造台**：画布上每一个圆都是一个神经元——拖拽移动、点击选中、右键删除；「连线模式」下点两个相邻层神经元即可搭（或拆）一条连接
- **实时训练**：学习率 / 动量 / 批大小 / 回合数 / 种子全可调，训练中权重随连线粗细与颜色实时变化，损失曲线与决策边界逐帧刷新
- **五个数据集**：
  | 数据集 | 输入 → 输出 | 看点 |
  | ------ | ---------- | ---- |
  | XOR 异或 | 2 → 1 | 直线分不开，必须有隐藏层 |
  | 双月 MOONS | 2 → 1 | 学习弯曲的决策边界 |
  | 螺旋 SPIRAL | 2 → 1 | 考验网络容量，加层才够 |
  | 手写数字 DIGITS | 35 → 10 | 位图字体 + 随机平移噪声，一窥图像识别 |
  | 井字棋 TIC-TAC-TOE | 9 → 9 | 向 minimax 完美教师学习，训练完跟它对弈 |
- **手写数字**：5×7 位图字模 + 平移/噪声增广，全程序化生成、种子可复现，无需任何外部素材
- **井字棋**：内置 minimax 教师生成「最优落子」数据集，网络学成后与它对战（✕ 先手 / ◯ 后手）

## 🎓 教学亮点

- **权重掩码**：删掉的连线在训练时不会被「复活」——体验剪枝如何让网络保持稀疏
- **逐神经元激活**：同一层的不同神经元可以混用 sigmoid / tanh / ReLU / LeakyReLU / 恒等
- **13 张知识卡**：神经元 → 权重 → 偏置 → 激活 → 前向 → 损失 → 反向传播 → 梯度下降 → 学习率 → 动量 → 批与回合 → 过拟合 → 种子确定性
- **训练场挑战**：每张挑战卡都有达标线，通关记录存本地

## 🚀 快速开始

```bash
cd synapse
.\start.bat                # 双击亦可：打开 index.html（Chrome / Edge）
node test/run.js           # 91 项单元测试（引擎 + 收敛 + 梯度校验 + 确定性）
node test/smoke-ui.js      # 前端冒烟测试（浏览器桩加载全部脚本 + 渲染路径）
```

## 📁 目录结构

```
synapse/
├── index.html              # 入口（双击即玩）
├── css/style.css           # 暗色神经实验室主题
├── js/
│   ├── shared/             # 纯逻辑引擎（Node 可测，零 DOM）
│   │   ├── rng.js          # 确定性随机数（mulberry32 + Box-Muller）
│   │   ├── activations.js  # sigmoid / tanh / ReLU / LeakyReLU / 恒等
│   │   ├── losses.js       # MSE / 交叉熵 / argmax / 准确率
│   │   ├── network.js      # 前向 / 反向传播 / 权重掩码 / 序列化
│   │   ├── trainer.js      # 小批量 SGD + 动量，确定性可复现
│   │   ├── datasets.js     # XOR / 双月 / 螺旋 / 手写数字（位图字体）
│   │   ├── tictactoe.js    # 井字棋规则 + minimax 教师
│   │   └── editor.js       # 网络图编辑器（层列模型，增删层/神经元/连线）
│   ├── render.js           # Canvas：网络图 / 损失曲线 / 决策边界 / 数字 / 井字棋
│   ├── audio.js            # Web Audio 程序化音效
│   └── main.js             # 主控制器（织造台 / 训练场 / 知识卡 / 存档）
├── test/
│   ├── run.js              # 91 项单元测试
│   └── smoke-ui.js         # 前端冒烟测试
└── start.bat               # 一键打开
```

## 🧪 测试说明

- **梯度校验**：解析反向传播 vs 数值差分（4 组网络结构，含混合激活与 softmax）
- **收敛测试**：XOR / 双月 / 螺旋 / 手写数字 / 井字棋全部按预设可达标
- **确定性**：同种子 → 相同权重初始化、相同洗牌、逐项相同的历史记录
- **掩码**：被剪枝的权重在训练后严格保持为 0
- **井字棋实战**：训练后对战随机玩家，胜+和 ≥ 170/200
