# 电路沙盒 · 设计文档

- 日期：2026-08-20
- 状态：已定稿，进入实现
- 分类：Architectural（仓库内全新项目，无现成流程可改）
- 驱动：superpowers SDD（spec → plan → 逐任务执行）

## 1. 概述

在浏览器里拖拽真实电路元件、连线、播放，看电流实时流过，用电压表/示波器测量，逐步解锁关卡学习电路知识。

一句话：**网页版的电路仿真 + 教学沙盒**，零依赖、离线可用。

## 2. 用户与目标

- 用户：对电路感兴趣的自学/教学者，以及想"搭着玩"的人。
- 成功标准：
  1. 拖入元件 → 连线 → 播放 → 能看到电流动画，数值正确。
  2. 至少 9 个关卡可玩通，每关有明确成功条件。
  3. 万用表/示波器测得的数值与手算一致（分压、RC 充电、逻辑真值表）。
  4. 一个中等复杂度电路（如 555 振荡器）能稳定跑出正确波形。

## 4. 引擎架构

### 4.1 数据模型

```
Circuit = {
  nodes: [{id, name}],
  components: [{
    id, type, terminals: [{nodeId, role}],
    params: {...},
    state: {...}   // 每步更新的历史态
  }]
}
```

每个元件 2 或 3 个端点，端点指向节点 id。

### 4.2 MNA 矩阵构造（核心）

未知量 = N 个节点电压 + K 个电压源支路电流。矩阵 (N+K)×(N+K)。

- **电阻**（a-b，R）：G[a][a]+=1/R，G[b][b]+=1/R，G[a][b]-=1/R，G[b][a]-=1/R。
- **电压源**（a-b，E）：新增一行一列。行：col[a]=+1、col[b]=-1；列：row[a]=+1、row[b]=-1；RHS[新行]=E。
- **电流源**（a→b，I）：RHS[a]+=I，RHS[b]-=I。
- **电容伴生模型**（梯形积分，Δt 固定 10µs）：等效电导 Geq=2C/Δt 并联等效电流源 Ieq=-Geq·Vc(t-Δt)-Ic(t-Δt)。在 a-b 间加电导 Geq + 电流源 Ieq。
- **电感伴生模型**：等效电导 Geq=Δt/(2L) 串联等效电压源 Veq=(2L/Δt)·Il(t-Δt)+Vl(t-Δt)。作为新电压源支路进矩阵。
- **逻辑门**：输出节点接一个电压源支路，源值 = 根据输入节点电压计算出的逻辑电平（高 5V / 低 0V），带传播延迟 τ（用延迟队列，输入变化后 τ 再影响输出）。门因此无需非线性迭代，可级联。
- **运放**：Vout = clamp(A·(V+ - V-), -Vcc, +Vcc)，作为电压源支路进矩阵。
- **二极管**（a-b，阳极 a）：非线性 I = Is·(exp(Vd/(n·Vt)) - 1)。牛顿-拉夫逊：贡献电导 gd = dI/dV = I/(n·Vt)，G 矩阵加 gd，RHS 加牛顿修正项 (I - gd·Vd)。
- **三极管 NPN**（e-b-c）：Ebers-Moll 传输模型。Vbe = Vb-Ve，Vbc = Vb-Vc。
  - Ib = Is/β · (exp(Vbe/Vt) - 1) + Is/β · (exp(Vbc/Vt) - 1)
  - Ic = Is · (exp(Vbe/Vt) - 1) - Is/β · (exp(Vbc/Vt) - 1)
  - Ie = -(Ib + Ic)
  - 进非线性迭代，牛顿法求 gd_be、gd_bc 与受控源修正项。
  - PNP 把电压/current 反号即可。

### 4.3 每步求解流程

1. 更新所有源的当前值（交流源按时间取样、时钟开关翻转）。
2. 根据上一拍输入 + 延迟队列，更新所有逻辑门输出电平。
3. 构造 MNA 矩阵 G 与 RHS 向量。
4. 非线性迭代（二极管、三极管）：最多 5 次，阻尼更新；不收敛则沿用上次值，保证不死机。
5. 高斯消元（部分主元）解线性系统。
6. 取节点电压；从解出的支路电流变量读取电压源/电感支路电流。
7. 更新电容/电感历史态，供下一拍伴生模型使用。
8. 触发渲染。

### 4.4 稳定性与性能

- Δt 固定 10µs（奈奎斯特 50kHz），倍速 1x/4x/16x。
- settle 按钮：跳过渲染，纯跑 N 步让慢电路快速达到稳态。
- 短路保护：两个不同值电压源并联 → 矩阵奇异 → 检测行列式≈0，抛"短路错误"提示，不崩溃。
- 元件数上限：不做硬限，但超过 ~100 节点会明显变慢（教学场景足够）。

## 5. UI 布局

### 5.1 三栏

```
[元件面板]        [画布 / 示意图]        [仪器面板]
 按类别分组        网格对齐               示波器
 拖拽到画布        导线自动走线            万用表
 点击放置          电流箭头动画            功率/能量读数
 右键删除          缩放/平移              触发/时基
 双击改参数        节点电压探针悬停显示
```

### 5.2 画布交互

- 拖入元件 → 自动落到最近网格点。
- 点击元件端点拖出导线，松手到另一元件端点自动连线；悬空导线提示"未连接"。
- 两指缩放/平移画布。
- 双击元件打开参数面板（改 R/C/L 值、源幅值、门真值表、运放增益）。
- 右键删除元件或导线。
- 播放时导线上按电流大小显示箭头（方向=电流方向，密度/长度=电流大小），节点电压悬停显示。

### 5.3 仪器

- **示波器**：双通道（A/B），各接一个节点。滚动波形，时基/伏特分度/触发（自动/上升沿）可调，可暂停。
- **万用表**：测两点间直流电压、某支路电流、等效电阻（内部加测试电流算）。
- **功率/能量**：显示当前总电源提供的瞬时功率。

### 5.4 顶部控制

播放/暂停/单步、倍速、settle、清空、保存（localStorage）、导入/导出 JSON、关卡选择器。

## 6. 关卡挑战

每关：标题 → 一句话提示 → 电路已预置（可改）→ 成功条件（测到目标电压/波形/频率）→ 通过解锁下一关 + 知识卡。

1. 点亮灯泡（电源+导线+负载）
2. 串联 vs 并联电阻（电流分流）
3. 二极管单向导电（半波整流波形）
4. 二极管搭 AND 门
5. 三极管开关（控制 LED）
6. RC 低通滤波（测截止频率）
7. 运放同相/反相放大器
8. 555 无稳态振荡器（方波发生器）
9. 逻辑门搭 1 位加法器（全加器）

## 7. 测试策略

`test/run.js`（node:test，零依赖）：

引擎层：
- 单电压源节点电压 = 源电压。
- 分压器 Vout = Vin·R2/(R1+R2)。
- 欧姆定律支路电流 I = V/R。
- 短路检测（两电压源并联 → 抛错）。
- 逻辑门真值表（NOT/AND/OR/NOR/XOR/XNOR）。
- RC 充电：电容电压随时间按指数趋近源电压，误差 <1%。
- 梯形积分无源电路能量不漂移（1000 步总能量变化 <0.1%）。
- 三极管放大区 Ic ≈ β·Ib。

UI 层（后续）：拖拽放置、连线、保存/导入往返。
