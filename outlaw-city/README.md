# 亡命都市 OUTLAW CITY 3D（GTA 风格开放世界游戏）

一个纯前端、零依赖的 **3D（Three.js）第三人称视角**开放世界犯罪动作游戏，直接用浏览器打开 `index.html` 即可游玩。

## 运行方式

直接双击打开 `index.html`（需要浏览器支持 WebGL）。也可用静态服务器：

```
npx serve .
```

## 3D 特性

- **全 3D 场景**：立体楼房（随机高度）、街道车道标线、湖泊水面、公园树木、街灯、远景雾效。
- **标准第三人称视角**：准星固定屏幕中央，点击画面锁定鼠标后用鼠标转动视角（Pointer Lock）；开车时镜头自动回正到车后，加速自动小幅拉远，`+`/`-` 可手动缩放。
- **动态光照**：太阳方向光 + 环境光随昼夜循环变化；夜晚街灯自动点亮（近处点光源）、车辆开启前灯聚光灯。
- **实时阴影**：建筑、车辆、角色投影；警车红蓝爆闪灯；车损起火、爆炸冲击波、子弹曳光、血液/火花/烟雾粒子。
- 玩法（驾驶、枪战、警察追捕、通缉星级、任务系统、昼夜循环、HUD/小地图）与 2D 版一致。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动（按镜头方向）/ 驾驶 |
| 点击画面 | 锁定鼠标（启用鼠标转动视角） |
| 鼠标（锁定后） | 移动鼠标转动视角，准星固定屏幕中央 |
| 左键 | 射击 |
| Esc | 退出锁定并暂停（点击画面继续） |
| Shift | 奔跑 |
| 鼠标 | 瞄准（射线投射到地面） |
| R | 换弹 |
| Q / 滚轮 / 1-6 | 切换武器 |
| + / - | 拉近 / 拉远镜头 |
| E | 上车 / 下车 / 接任务 |
| 空格 | 漂移 |
| Esc / Enter | 暂停 / 开始 |

## 文件结构

```
outlaw-city/
├── index.html
├── css/style.css
├── lib/three.min.js      # three.js r128 引擎
└── js/
    ├── render3d.js       # 3D 渲染器（世界/实体/光照/镜头/粒子）
    ├── main.js           # 主循环（3D 渲染 + 2D HUD）
    ├── utils.js / config.js / input.js / audio.js
    ├── map.js            # 城市地图数据（与 2D 版共享）
    ├── entities.js       # 玩家/载具/NPC/拾取物逻辑
    ├── combat.js / ai.js / police.js
    ├── missions.js       # 任务系统
    └── hud.js            # HUD 与小地图（2D 覆盖层）
```

## 提示

- 开局先做“新手上路”任务熟悉驾驶。
- 抢警车会直接涨通缉星；火箭筒适合“终极对决”的卡车车队。
- 夜晚开车记得开前灯（自动亮起），街灯会在你附近自动点亮。
