# 亡命都市 OUTLAW CITY 3D（GTA 风格开放世界游戏）

纯前端、零依赖的 **3D（Three.js r128）第三人称开放世界犯罪动作游戏**，直接用浏览器打开 `index.html` 即可游玩。

- 技术栈：原生 HTML / CSS / JavaScript + 本地化的 `lib/three.min.js`，无构建步骤、无 npm 依赖、无后端。
- 平台要求：支持 WebGL 的桌面浏览器。若 WebGL 不可用，游戏不会崩溃，而是在画面上给出明确提示并降级显示 HUD。

## 运行方式

直接双击打开 `index.html`。也可以用任意静态服务器（可选，需要联网下载 `serve`）：

```
npx serve .
```

## 测试

零依赖 Node 脚本（浏览器桩 + 真实断言，覆盖 3D 渲染与主循环路径）：

```
node test/run.js
```

脚本按 `index.html` 的顺序加载全部前端脚本，校验全局命名空间，然后断言数学工具、地图生成与碰撞、输入映射、玩家/武器、载具物理、战斗、任务状态机、警察系统、NPC 生命周期、昼夜循环、3D 渲染与镜头、主循环，以及“画布尺寸为 0 / WebGL 不可用”的降级路径。末尾打印通过项数，失败时 `exit(1)`。

## 玩法与特性

**3D 场景**
- 13×13 街区程序化生成：立体楼房（随机高度）、车道标线、湖泊水面、公园树木、街灯、远景雾效。
- 第三人称视角：准星固定屏幕中央；点击画面用 Pointer Lock 锁定鼠标后转动视角；开车时镜头自动回正到车后，速度越快镜头越远，`+`/`-` 可手动缩放。
- 动态光照：太阳方向光 + 环境光随昼夜循环（默认 10 分钟一天）变化；夜晚最近 10 盏街灯自动点亮（点光源），玩家车辆自动开启前灯聚光灯。
- 实时阴影：建筑、车辆、角色均投影；警车红蓝爆闪灯；车损起火、爆炸冲击波、子弹曳光、血液/火花/烟雾粒子。
- 摄像机穿楼保护：镜头落进建筑时自动抬升到楼顶以上。

**玩法系统**
- 驾驶：油门/刹车/转向、手刹漂移、碰撞损伤、车辆起火与爆炸、车与车之间的推挤解算。
- 枪战：拳头/手枪/冲锋枪/霰弹枪/步枪/火箭筒 6 种武器；弹匣与备弹分离，含换弹、散布、霰弹多弹丸、火箭筒溅射。
- 警察与通缉：0–5 星通缉等级；警车从地图边缘包夹、下车步战；被贴近且残血时会被捕（罚款 10%），甩掉视野一段时间后星级自动下降。
- NPC：平民游荡/听到枪声逃跑、帮派成员与老大主动交战、警察步战；尸体 30 秒后回收，市区人口自动补充。
- 拾取物：金钱、生命、护甲、弹药。
- 昼夜循环：HUD 右上角显示游戏内时钟，天空色、雾色、光照强度随之变化。
- HUD：生命/护甲条、金钱、通缉星、武器与弹药、任务提示、通知、小地图（含车辆/NPC/任务点）。
- 音频：WebAudio 合成的枪声、爆炸、警笛、引擎声与任务音效（无 WebAudio 时静音降级）。

**任务**
7 个剧情任务，按顺序在黄色 `?` 标记处接取：新手上路 → 城市出租 → 帮派清剿 → 追捕逃犯 → 定时炸弹 → 枭雄陨落 → 终极对决，奖励 $300–$8000。完成“城市出租”后解锁可重复接取的出租车生意（绿色 `T` 标记）。任务失败会清理本任务生成的载具与 NPC。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动（按镜头方向）/ 驾驶 |
| 点击画面 | 锁定鼠标（启用鼠标转动视角） |
| 鼠标（锁定后） | 移动鼠标转动视角，准星固定屏幕中央；未锁定时鼠标偏离屏幕中心也会转向 |
| 左键 | 射击（未锁定时首次点击只用于锁定鼠标，不会走火） |
| Esc | 退出锁定并暂停（点击画面继续） |
| Shift | 奔跑 |
| R | 换弹 |
| Q / 滚轮 / 1-6 | 切换武器 |
| + / - | 拉近 / 拉远镜头 |
| E | 上车 / 下车 / 接任务 |
| 空格 | 漂移（手刹） |
| Enter | 开始游戏 |

## 文件结构

```

├── css/style.css

├── test/run.js           # 零依赖测试（node test/run.js）
└── js/
    ├── render3d.js       # 3D 渲染器（静态世界/实体同步/光照/镜头/粒子）

    ├── utils.js          # 数学与随机工具
    ├── config.js         # 世界/玩家/载具/武器/NPC/警察数值
    ├── input.js          # 键盘、鼠标、滚轮、Pointer Lock
    ├── audio.js          # WebAudio 合成音效
    ├── map.js            # 城市程序化生成、碰撞查询、小地图位图
    ├── entities.js       # Player / Vehicle / NPC / Pickup
    ├── combat.js         # 子弹、粒子、爆炸、命中判定
    ├── ai.js             # 交通 AI / 警察 AI / 护送 AI
    ├── police.js         # 通缉等级、警车编队、下车步战、被捕
    ├── missions.js       # 任务定义与任务状态机
    └── hud.js            # HUD 与小地图绘制、昼夜光照曲线
```

## 提示

- 开局先做“新手上路”任务熟悉驾驶。
- 抢警车会直接涨通缉星（抢来的警车不会再被警察编队收回）。
- 火箭筒适合“终极对决”的卡车车队。
- 夜晚开车记得开前灯（自动亮起），街灯会在你附近自动点亮。

## 已知限制

- 没有存档，刷新页面即重新开局。
- 只有键鼠操作，没有触屏/手柄支持。
- 建筑允许互相重叠，极少数重叠夹缝里碰撞解算会残留一帧抖动（实体每帧都会被推出，不会永久卡死）。
- 出租车生意是目前唯一的可重复内容；剧情任务可重玩，但重复完成不再增加剧情进度。
