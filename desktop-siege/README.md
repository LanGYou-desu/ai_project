# DESKTOP SIEGE · 桌面保卫战

> 一个**从你电脑的真实数据里长出敌人**的桌面防御射击游戏：启动时游戏会扫描你
> 的用户目录（桌面 / 文档 / 下载 / 图片…）和系统进程，把**真实文件名**变成敌人——
> 你下载过的 `crackme.exe`、写过的 `毕业论文终版.docx`、跑着的 `svchost`……
> 每台电脑的战场都独一无二。你的"家园"就是你的桌面。

- 类型：俯视双摇杆防御射击（Canvas 动作游戏）
- 技术栈：Node.js（零第三方依赖）+ 原生 Canvas / Web Audio
- 时长：20 波 + 4 个 Boss + 无尽模式，一局 30–60 分钟，可反复挑战
- 敌人全部以真实文件名 + 扩展名行为生成（exe 冲锋、pdf 重甲、zip 分裂、jpg 治疗…）

## 玩法

- WASD / 方向键移动，鼠标瞄准，按住左键射击。
- 击杀敌人得分、攒连击；敌人掉落 6 种道具：极速 / 散射 / 护盾 / 修复 / 冻结 / 穿透。
- 每 5 波一个 Boss（第 5 / 10 / 15 / 20 波），Boss 以你磁盘上最大的文件命名。
- 20 波后进入无尽模式，敌人与轮次同步增强。

## 快速开始

```bat
start.bat
```

或 `node server.js`，浏览器打开 http://127.0.0.1:8769。首次启动会扫描磁盘
（数百到数千个真实文件），之后可点"重新扫描"更新敌人池。

## 敌人类别（由扩展名决定）

| 类别 | 典型扩展名 | 行为 |
| ---- | ---------- | ---- |
| 炮灰 | txt / doc / md | 慢速小怪 |
| 冲锋者 | exe / msi / lnk | 高速直冲 |
| 重甲 | pdf / zip / iso | 高血量慢速 |
| 分裂者 | zip / rar / 7z | 死后裂成 3 个碎片 |
| 虫群 | dll / sys / dat | 成群小怪 |
| 治疗者 | jpg / png / mp4 | 远程治疗同伴 |
| BOSS | 你磁盘上最大的文件 | 弹幕 + 高血量 |

Boss 弹幕 / 无尽模式 / 服务器冒烟）。

## 目录结构

```
desktop-siege/
├── server.js            # 服务器：真实磁盘扫描 + 波次 API + 静态资源
├── lib/
│   ├── scanner.js       # 真实磁盘 / 进程扫描（含缓存）
│   ├── waves.js         # 20 波 + 无尽波次生成（确定性）
│   ├── engine.js        # 纯逻辑游戏引擎（Node + 浏览器双模式 UMD）
│   └── rng.js           # 种子随机数
├── public/              # Canvas 游戏界面（index.html / style.css / game.js）
├── test/run.js          # 测试
├── scan-cache.json      # 扫描缓存（不入库）
└── start.bat
```
