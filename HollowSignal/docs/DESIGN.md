# 设计文档

## 设计支柱

1. **声音是空间本身**  
   研究站不是一个有音效的房间，而是一台仍在聆听的机器。玩家听到的对讲机、磁带、广播、脚步和阵列嗡鸣，都在提示空间的状态，也在暴露自己的位置。

2. **一路向下，不能回头**  
   四章线性下潜：检修隧道 → 泵层 → 船员层 → 共振展厅。电梯是章节之间的门，也是无法回头的分界线。每一章都比上一章更接近阵列，也更接近艾瑞斯不愿承认的事实。

3. **恐怖来自可解释的细节**  
   没有跳吓堆叠。恐怖建立在台灯的温度、被刮花的照片、过于平静的官方措辞、观察窗后的轮廓，以及“声音还在回答”的日常感上。

4. **玩法必须说故事**  
   找卡、装保险丝、输入妹妹的工牌号码、躲进储物柜、听完磁带。每个交互都同时是解谜、角色行为与主题陈述。

5. **中文不是翻译层，而是界面本身**  
   章节标题、档案、目标、字幕、标牌和按钮都直接以中文写作；排版按中文重新调整字距、行高、标题尺度和面板宽度，而不是在英文 UI 上替换字符串。

## 玩家体验曲线

| 阶段 | 玩家感受 | 设计手段 |
| --- | --- | --- |
| 第一章 | 不安、怀念、否认 | 狭窄检修隧道、温暖台灯、第一段对讲机人声 |
| 第二章 | 好奇、修复、被观察 | 泵层探索、三枚保险丝、观察窗轮廓、蕾恩的磁带 |
| 第三章 | 紧张、被追、必须行动 | 密码锁、储物柜、脚步噪声、聆听者追逐 |
| 第四章 | 面对、哀伤、不可逆 | 记忆走廊、最终磁带、双结局选择 |

## 核心循环

1. 观察环境，辨认可交互物。
2. 阅读档案或取得物品，目标面板更新。
3. 解开一个空间谜题（刷卡、装保险丝、输密码、恢复供电）。
4. 开启下一段路径，环境音与灯光状态改变。
5. 在安全点保存进度；死亡后回到最近的安全点。

## 关卡设计

### 第一章：低水位

- **教学**：移动、手电筒、交互、读卡器、电梯。
- **空间**：一条狭窄检修隧道、一个维修办公室、一个安保门厅。
- **节奏**：慢速探索，先给声音，再给物体，最后给门。
- **关键道具**：检修卡。
- **视觉锚点**：被水浸皱的剪报、仍然亮着的台灯、电梯井的冷气。

### 第二章：聆听层

- **空间**：泵层大厅、观察室、断路器区、货运电梯。
- **谜题**：三枚陶瓷保险丝必须全部装回，断路器拒绝残缺负载。
- **转折**：恢复供电后，观察窗后出现轮廓；蕾恩的磁带和工牌开始把“事故”变成“家庭史”。
- **节奏**：探索 → 收集 → 合闸 → 看见 → 离开。

### 第三章：薄墙

- **空间**：船员层走廊、安保办公室、变电站、储物柜、追逐路线、电梯。
- **谜题**：四位密码 `0317`。工牌上的数字既是密码，也是妹妹的年龄线索。
- **机制**：聆听者通过声音定位；冲刺最吵，行走中等，蹲伏最安静；储物柜提供短时安全。
- **失败**：死亡后回到最近安全点，不惩罚整章重来。
- **节奏**：安静搜索 → 键盘 → 恢复电力 → 追逐 → 逃生。

### 第四章：空洞

- **空间**：记忆走廊、共振展厅、阵列核心、控制台。
- **结构**：走廊两侧的门是不可进入的记忆片段；展厅是最终舞台。
- **节奏**：低速、仪式感、长对白、最终选择。
- **选择**：切断电源（静水）或回答信号（空洞）。选择后立即进入结局，无法撤销。

## 交互与反馈

- **准星附近提示**：交互键、动作名称、补充说明。
- **目标面板**：当前目标与子目标；章节变化时短暂显示章节卡。
- **案件记录**：档案、录音、工牌与便条统一收集；记录可反复阅读。
- **字幕**：对讲机、磁带、信号与站内广播都带说话者名称。
- **噪声指示**：第三章显示脚步噪声等级；冲刺、行走、蹲伏对应不同状态。
- **手电筒**：唯一可靠光源；开关状态显示在物品栏。
- **藏身处**：进入储物柜后画面边缘收窄，提示按 `E` 离开。

## 难度与可访问性

- 没有传统难度选择；难度由声音管理、路线选择与追逐压力自然形成。
- 三档画质：低、中、高，影响渲染分辨率、像素比、MSAA、阴影分辨率、粒子密度、雾距离、各向异性、斜向剔除距离与 LOD 偏置。
- 可调视角灵敏度、主音量、胶片颗粒、视野。
- 字幕可关闭；减少动态效果会降低头部晃动、镜头摇摆与脉冲效果。
- 不使用快速反应事件；密码与谜题可以无限重试。
- 键盘布局固定为 WASD；界面明确列出按键。

## 界面与中文排版

- 字体：`Noto Sans SC` 用于 HUD、菜单、按钮与说明；`Noto Serif SC` 用于标题、章节卡、档案与结局。
- 中文标题使用更宽松的字距与更高的行高；英文原版的窄体大标题改为适合方块字的两行式标题。
- 微型标签（如“当前目标”“现场终端”）提高字号、降低字距，避免中文在 7–9px 时不可读。
- 档案纸张保留等宽/打字机质感，但正文使用中文宋体，保证长文可读。
- 所有界面文案直接写在 HTML 或 `content.js` 中，不依赖运行时语言切换。

## 视觉与音频

- **视觉**：程序化混凝土、金属、锈蚀、水渍、纸张与灯光；没有第三方 3D 模型或摄影素材。静态几何合批，烘焙光照，雾与暗角建立深度。
- **音频**：流式 WAV 环境声按章节切换；对讲机、磁带、脚步、金属撞击与阵列嗡鸣为程序化/本地音效。字幕与声音事件同步。
- **色彩**：低饱和绿灰、暖琥珀、锈红。暖色只出现在人曾经待过的地方，冷色属于水与阵列。

## 保存与重玩

- 单槽位自动存档，保存章节、检查点、物品、档案与目标。
- 继续游戏从最近章节检查点开始；章节内死亡回到最近安全点。
- 通关后可以重新开始本章，体验另一个结局。
- 设置单独保存，不随存档清除。

## 内容边界

游戏包含心理压迫、感官失真、暗示性死亡与哀伤描写，不包含血腥特写或直接暴力画面。建议佩戴耳机，并在不被打扰的环境中游玩。
