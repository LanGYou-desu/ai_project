# 🌱 ECO-ARK 生态方舟

> **微观生态重建模拟器**：2097 年，苔原星生态崩溃。作为生态方舟的管理员，你从一株苔藓开始，亲手重建从生产者到顶级掠食者的完整食物网，并让它挺过干旱、冰期、陨石与外来物种入侵——整整一百二十年。
>
> **6 章剧情（16 项目标）+ 沙盒模式 + 21 种物种 + 13 条生态学知识卡 + 12 项成就 + 可复现种子存档**。

| 类型 | 纯前端 Web 模拟器（零依赖） |
| ---- | ---- |
| 技术栈 | 原生 HTML/CSS/JS + Canvas + Web Audio（程序合成环境音） |
| 测试 | `node test/run.js`（59 项单元测试：确定性 / 生态平衡 / 剧情目标 / 存档兼容 / 时间步进） |
| 运行 | 双击 `start.bat` 或直接打开 `index.html`（推荐 Chrome / Edge） |

---

## 🎮 怎么玩

1. 主菜单选择 **剧情模式**（6 章 · 16 项目标）或 **沙盒模式**（自由演化）。
2. 在左侧选择物种，回到培养皿上 **按住左键涂抹**：
   - 🌿 **植物**：涂抹一次 = 播下一片种子，之后它会自行扩散。
   - 🐾 **动物**：涂抹 = 放生个体。
   - 🧹 **除草 / 🧪 施肥 / 🔍 查看**：三个干预工具。
3. 顶部 **1× / 2× / 4× / 8× / 16×** 调速（1× = 1 年/秒，16× = 16 年/秒）。右侧实时观看 **种群动态曲线**——洛特卡-沃尔泰拉式的捕食-猎物波动会自然涌现。
4. 完成章节目标 → 获得 **1~3 星评价** → 解锁新物种与生态学知识卡。

> 纯演化 244 年（六章合计）：4× 约 1 分钟、1× 约 4 分钟。实际通关时长取决于你的放置、观察与暂停操作。

## 📖 剧情六章（16 项目标）

| 章 | 目标 | 主题 | 你将学到 |
| -- | ---- | ---- | ---- |
| 1 · 播种纪元 | 2 | 亲手种下 3 种植物，覆盖率 ≥ 22% 并保持 3 年 | 生产者与能量起点 |
| 2 · 草原呼吸 | 2 | 食草动物 ≥ 60 保持 8 年，植被始终 > 8% | 消费者、承载量 |
| 3 · 王者降临 | 3 | 三层食物网共存 10 年、捕食者 ≥ 15 保持 5 年、见证营养级联 | 营养级、洛特卡-沃尔泰拉、营养级联 |
| 4 · 冰河时代 | 3 | 冰期（约 2.5 年）每年 ≥ 3 物种存活、耐寒物种存活、冰期后生物量恢复 50% | 生态韧性、K/r 对策 |
| 5 · 入侵警报 | 3 | 藤蔓爆发 ≥ 15%、压回 < 30% 保持 10 年、本土覆盖反超 | 入侵物种、生态位 |
| 6 · 千年方舟 | 3 | 自主运行 120 年、物种多样性 ≥ 8、稳定性 ≥ 0.6 保持 10 年 | 生物多样性、养分循环 |

每章结束后按 **多样性 × 稳定性 × 生物量** 综合评分，全 6 章最高 18 星，通关后获得 S/A/B/C 最终评级。

## 🌍 物种系统（21 种）

- **生产者（9）**：苔原苔藓、草原禾草、耐旱灌木、落叶乔木、水生藻类、河岸芦苇、砂原仙人掌、巨型蕨类、外来藤蔓（入侵物种）。
- **消费者（11）**：草间昆虫、草甸田鼠、原野野兔、林间白鹿、长毛猛犸、浅水鲦鱼（食草）；林间织蛛、赤尾狐狸、灰原狼群、巡天苍鹰、巨蜥潜客（捕食）。
- **分解者（1）**：腐生真菌（尸体 → 养分的循环由引擎模拟）。

每种物种拥有独立生态位：地形偏好、温湿度舒适区、代谢率、寿命、繁殖策略（r/K 对策）、食性。物种按章节逐步解锁；剧情模式下外来藤蔓只能通过第五章的入侵事件进入（沙盒模式可直接放置）。

## 🧪 仿真引擎

- **能量流动**：阳光 → 植物生物量 → 食草动物 → 捕食者 → 尸体 → 分解 → 养分 → 植物。转化效率为游戏化参数：植物→食草 55%、食草→捕食 80%（现实生态学的 10% 定律见知识卡）。
- **水分/养分/气温**：逐格模拟，季节波动 + 随机气候事件（干旱、热浪、冰期、陨石、瘟疫、丰年、藤蔓入侵）。冰期会把全图气温压低约 15℃（严冬最低约 -7℃）。
- **确定性**：同一种子 + 相同操作序列 → 完全相同的演化（逐字节一致），支持「种子 + 操作日志」存档重放与分享。
- **稳定机制**：功能响应（猎物稀缺时捕食成功率下降）、繁殖的猎物/捕食者比例闸门、地形庇护所、残存种群庇护——未管理的生态也会出现真实的暴涨-崩溃-复苏循环，而不会瞬间灭绝。
- **性能**：逐格植物生长查表化（静态地形适配 + 每步温度适配）、邻域查询走整数分桶计数、存活数量增量维护、`getStats()` 按脏标记缓存。同规模场景下每模拟月耗时约为初版的 1/4，且结果逐字节不变。

## 📚 生态学知识卡（13 条）

能量金字塔与 10% 定律、生产者/消费者/分解者、营养级、洛特卡-沃尔泰拉方程、生态位、K/r 对策、营养级联、生物多样性、生态韧性、承载量、养分循环、入侵物种。每条知识卡都有「在本模拟中如何观察」指引——边玩边学真实生态学。13 张卡在六章结算中依次解锁，不重复、不遗漏。

## 🏆 成就（12 项）

初次播种、绿意盎然、牧群建立、三层食物网、顶级繁衍、冰期幸存者、藤蔓克星、生物多样性、稳固方舟、百年守望、营养级联、方舟建筑师。

## 💾 存档与降级

- 存档写在浏览器 localStorage：**种子 + 操作日志 + 章节状态**，读档时按日志完整重放，结果与存档前逐字节一致。
- 存档格式带版本号（当前 v2）；读档会校验字段完整性与版本区间，损坏或未来版本的存档会被安全忽略；v1 旧存档缺少的章节字段用默认值补齐。
- 存档面板（顶栏 💾）可查看当前种子与操作数；保存后返回主菜单即可看到「继续上次的方舟」。
- 若浏览器不提供 Canvas 2D 或 Web Audio，游戏自动降级：画布渲染/涂抹、曲线、环境音分别停用，章节流程与面板仍可正常进行。

## 🚀 运行与测试

```bash
# 玩游戏
.\start.bat          # 或直接双击 index.html

# 单元测试（59 项，约 4 秒）
node test/run.js

# 开发辅助
node scripts/calibrate.js       # 打印标准场景的种群动态
node scripts/smoke-browser.js   # 浏览器启动冒烟（模块加载 + 菜单渲染 + 存档重放）
node scripts/verify-campaign.js # 自动玩家验证 6 章全部可通关
```

> 声音为 Web Audio 程序合成，建议佩戴耳机，可在顶栏静音。开发辅助脚本只依赖 Node 内置模块，不安装任何第三方依赖。
