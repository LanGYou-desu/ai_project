# SYNAPSE · 神经织造

> **亲手搓一个神经网络，看着它学会思考。**
>
> 不写一行框架代码：在画布上拖拽连线搭网络、调权重、改偏置、换激活函数，然后点「开始训练」——损失曲线当场下降、决策边界在眼前成形。五个数据集从 XOR 一路打到井字棋，训练场里还有五张「毕业证」等着你。

| 项目 | 说明 |
| ---- | ---- |
| 类型 | 神经网络教学沙盒（可视化 + 可交互 + 可训练） |
| 技术栈 | 原生 HTML/CSS/JS + Canvas + Web Audio + Node.js（零第三方依赖） |
| 规模 | 手写反向传播引擎 + 5 个数据集 + 训练场 5 大挑战 + 13 张知识卡 + 权重掩码（稀疏剪枝）+ 存档导入导出 |
| 测试 | `node test/run.js`（141 项单元测试）+ `node test/smoke-ui.js`（前端冒烟 + 渲染缓存断言） |

## 🧠 核心玩法

- **织造台**：画布上每一个圆都是一个神经元——拖拽移动、点击选中、右键删除；「连线模式」下点两个相邻层神经元即可搭（或拆）一条连接
- **实时训练**：学习率 / 动量 / 批大小 / 回合数 / 种子全可调，训练中权重随连线粗细与颜色实时变化，损失曲线与决策边界逐帧刷新
- **五个数据集**：
  | 数据集 | 输入 → 输出 | 样本数 | 看点 |
  | ------ | ---------- | ------ | ---- |
  | XOR 异或 | 2 → 1 | 4 | 直线分不开，必须有隐藏层 |
  | 双月 MOONS | 2 → 1 | 120 | 学习弯曲的决策边界 |
  | 螺旋 SPIRAL | 2 → 1 | 140 | 考验网络容量，加层才够 |
  | 手写数字 DIGITS | 35 → 10 | 600 | 位图字体 + 随机平移噪声，一窥图像识别 |
  | 井字棋 TIC-TAC-TOE | 9 → 9 | 500 | 向 minimax 完美教师学习，训练完跟它对弈 |
- **手写数字**：5×7 位图字模 + 平移/噪声增广，全程序化生成、种子可复现，无需任何外部素材
- **井字棋**：内置 minimax 教师生成「最优落子」数据集，网络学成后与它对战（✕ 先手 / ◯ 后手）
- **准确率是算出来的**：单输出（sigmoid）按 0.5 阈值判类，多输出按 argmax；二分类数据集不再「开局就 100%」

## 🎓 教学亮点

- **权重掩码**：删掉的连线在训练时不会被「复活」——体验剪枝如何让网络保持稀疏
- **逐神经元激活**：同一层的不同神经元可以混用 sigmoid / tanh / ReLU / LeakyReLU / 恒等
- **13 张知识卡**：神经元 → 权重 → 偏置 → 激活 → 前向 → 损失 → 反向传播 → 梯度下降 → 学习率 → 动量 → 批与回合 → 过拟合 → 种子确定性
- **训练场挑战**：每张挑战卡都有达标线，通关记录存本地（XOR ≥ 95% / 双月 ≥ 90% / 螺旋 ≥ 80% / 数字 ≥ 90% / 井字棋教师落子 ≥ 80%）
- **发散看得见**：学习率大到梯度爆成 NaN/Inf 时，训练会立刻停下并保留上一回合的有限权重，而不是把权重写成 NaN

## 🧪 测试说明

- **梯度校验**：解析反向传播 vs 数值差分（8 组网络结构，含混合激活、softmax+MSE、多标签 sigmoid、深网络）
- **收敛测试**：XOR / 双月 / 螺旋 / 手写数字 / 井字棋全部按预设可达标（含挑战达标线本身）
- **确定性**：同种子 → 相同权重初始化、相同洗牌、逐项相同的历史记录
- **掩码**：被剪枝的权重在训练后严格保持为 0
- **井字棋实战**：训练后对战随机玩家，胜+和 ≥ 170/200、胜局 ≥ 120/200
- **鲁棒性**：极端学习率触发发散保护（权重保持有限）、空数据集 / 维度不符 / 损坏存档 JSON 一律明确报错
- **渲染缓存**：冒烟测试断言「同一权重第二次绘制决策边界不再逐格前向、权重变化后自动重算」

## 🔬 实现备注

- **反向传播**：MSE + softmax 用完整雅可比 `dL/dz_j = a_j·(g_j − Σ_i g_i·a_i)`（不是把 softmax 当恒等映射）；交叉熵要求输出层是 sigmoid 或 softmax，否则直接报错而不是静默算错
- **训练循环**：梯度累加进预分配缓冲（`initGrads` / `zeroGrads`），每批零分配；`backward` 顺带返回本次前向的输出，省掉一次重复 `predict`
- **决策边界**：56×56 逐格前向的结果按「权重签名 + 尺寸 + 坐标范围」缓存到离屏画布，权重不变时只做一次 `drawImage`
- **井字棋教师**：minimax 带置换表（全部可达局面约 5.5k 个），数据集生成从秒级降到毫秒级，结果与无缓存完全一致
- **画布**：尺寸未变化时不再重写 `canvas.width/height`，避免每帧重新分配后备缓冲
