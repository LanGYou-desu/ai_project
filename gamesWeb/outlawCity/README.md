# 亡命都市 OUTLAW CITY 3D（GTA 风格开放世界游戏）

纯前端、零依赖的 **3D（Three.js r128）第三人称开放世界犯罪动作游戏**，直接用浏览器打开 `index.html` 即可游玩。

- 技术栈：原生 HTML / CSS / JavaScript + 本地化的 `lib/three.min.js`，无构建步骤、无 npm 依赖、无后端。
- 平台要求：支持 WebGL 的桌面浏览器。若 WebGL 不可用，游戏不会崩溃，而是在画面上给出明确提示并降级显示 HUD。

## 运行方式

直接双击打开 `index.html`。也可以用任意静态服务器（可选，需要联网下载 `serve`）：

```
npx serve .
```

舞台固定为 16:9 并随窗口自适应；推荐 1600×900 及以上分辨率、开启全屏（F11）游玩。窗口不是 16:9 时画面上下或左右会留出暗色边框，游戏内容不会被拉伸。

### 界面与高分屏

- HUD、菜单和过场文字仍按 **1280×720 设计坐标** 排版，但实际画布会按“CSS 尺寸 × 设备像素比（上限 2）”重建，再用 `setTransform` 映射回设计坐标，因此高分屏上的文字、准星和小地图不会被整体放大成一团糊。
- 3D 画布使用真实画面宽高比和相同像素比；1600×900 在 DPR 1 下使用 1600×900 缓冲，在 DPR 2 下使用 3200×1800 缓冲。窗口缩放或 DPR 改变后 `resize` 会重建两块画布并刷新 HUD 变换，不会把旧分辨率锁死。页面不再把 1280×720 的画布硬拉伸到全屏。
- 已移除全屏扫描线叠层；暗角只作用于 3D 场景，不会压暗 HUD。

## 测试

零依赖 Node 脚本，**253 项断言**（浏览器桩 + 真实断言，覆盖 3D 渲染与主循环路径）：

```
node test/run.js
```

脚本按 `index.html` 的顺序加载全部前端脚本，校验全局命名空间，然后断言数学工具、地图生成与碰撞、输入映射、玩家/武器、载具物理、战斗、任务状态机、警察系统、NPC 生命周期、昼夜循环、3D 渲染与镜头、主循环，以及“画布尺寸为 0 / WebGL 不可用”的降级路径。末尾打印通过项数，失败时 `exit(1)`。

## 玩法与特性

**3D 场景**
- 13×13 街区程序化生成：立体楼房（随机高度）、车道标线、湖泊水面、公园树木、街灯、远景雾效。
- 城市地标与不规则构图：中央公园步道、铺装广场、八角/三角塔楼、斜切楼角、霓虹广告牌、跨街天桥、斜向单轨列车和远景针塔；路口加入琥珀色斜向人行横道，远景楼体也补上了亮窗面，避免整座城市只剩横平竖直的盒子。
- 第三人称肩后镜头：准星固定屏幕中央，角色常驻准星左侧，越肩偏移会随镜头缩放等比保持；步行默认使用约 15.5 单位的弹簧臂，右键精确瞄准时平滑收近到约 12.5 单位并收窄 FOV、加大肩位。开车时使用更低的车后 3/4 追车视角，距离随车长缩放，镜头向前预瞄，速度越快视野越宽、过弯有轻微侧倾；停车时可用鼠标绕车观察，行驶中 1 秒没有鼠标输入后自动回正；下车时保留当前观察方向，只切换回步行肩位。`+`/`-` 可在 0.72–1.45 倍范围手动缩放，步行和驾驶通用。
- 动态光照：太阳方向光 + 环境光随昼夜循环（默认 10 分钟一天）变化；夜晚最近 10 盏街灯自动点亮（点光源），玩家车辆自动开启前灯聚光灯。
- 实时阴影：建筑、车辆、角色均投影；警车红蓝爆闪灯；车损起火、爆炸冲击波、子弹曳光、血液/火花/烟雾粒子。
- 近景细节：近处楼体的消防梯、窗式空调、竖向霓虹在湿地面的倒影、高楼航空障碍灯，以及英雄超市招牌的轻微闪烁。
- 摄像机穿楼保护：从角色/车辆的枢轴向理想机位做 3D AABB 检测，连同楼顶高度一起判断；被楼体挡住时立即收臂，离开遮挡后平滑退回。镜头被挤到角色身边时会自动隐藏角色模型，不穿墙、也不会突然跳到楼顶。

**角色、车辆与人群**
- 玩家与 NPC 共用模块化低多边形角色，但玩家有独立红风衣：前襟收窄、中缝拆开的后摆、短围巾尾、斜背枪带、腰带扣、枪套和深色手套；所有角色统一采用 `+X` 正面，转身、举枪和上下车时不会再出现“背对镜头跑”的朝向错误。
- NPC 具备 8 套服装/体态组合，帽子与发型、肩宽、围巾、游客裙装/背包、工装工具包会随机混搭；平民、帮派成员、老大、警察各有独立武器与行为。
- 12 种车型：`sedan / sports / taxi / police / truck / bike / van / suv / pickup / bus / muscle / limo`。车身高度和轮径重新配比，轿车/跑车降低车身、放大轮胎；出租车用紧凑顶灯，警车有黑白车门、白车顶和红蓝灯条，跑车改为贴面鸭尾而不是悬空尾翼，皮卡有完整货斗侧板，摩托有连贯车架。追车镜头与车辆体量匹配，侧面不再是一块贴地的钢板。
- 开局约 54 名 NPC（广场、超市和市中心东侧街段有固定人群），平民补充上限 36（死亡尸体会暂时占用数量）；初始 34 辆交通车和 24 辆路边停车，动态交通上限 38，市中心四个路口及东侧街段另有固定停车。


**玩法系统**
- 驾驶：油门/刹车/转向、手刹漂移、碰撞损伤、车辆起火与爆炸、车与车之间的推挤解算。
- 枪战：拳头/手枪/冲锋枪/霰弹枪/步枪/火箭筒 6 种武器；弹匣与备弹分离，含换弹、散布、霰弹多弹丸、火箭筒溅射；自动武器按住连射，半自动武器逐次点击。
- 警察与通缉：0–5 星通缉等级；警车从地图边缘包夹、下车步战；被贴近且残血时会被捕（罚款 10%），甩掉视野一段时间后星级自动下降。
- NPC：平民游荡/听到枪声逃跑、帮派成员与老大主动交战、警察步战；尸体 30 秒后回收，市区人口自动补充。
- 拾取物：金钱、生命、护甲、弹药。
- 昼夜循环：HUD 右上角显示游戏内时钟，天空色、雾色、光照强度随之变化。
- HUD：切角暗色面板组成的信息层——左上角现金与生命/护甲，右侧通缉星和程序化高清小地图（含车辆/NPC/任务点），顶部任务滚动条，底部武器卡、载具卡和圆形速度表；另有中央准星、交互提示、通知栈和低血量屏幕边缘泛红。危险状态用琥珀色，城市/任务信息用青色，避免所有数字挤在同一块灰色面板里。
- 界面：菜单、暂停、WASTED / BUSTED 结算层全部重排为切角面板、大字号标题和暗色霓虹风格；“行动手册”按驾驶/枪战/城市探索分组，右上角保留地图规模、时钟和通缉等级摘要。菜单可点击画面或按 Enter 开始，暂停后点击画面或按 Esc 继续。
- 音频：WebAudio 合成的枪声、爆炸、警笛、引擎声与任务音效（无 WebAudio 时静音降级）。

**任务**
7 个剧情任务，按顺序在黄色 `?` 标记处接取：新手上路 → 城市出租 → 帮派清剿 → 追捕逃犯 → 定时炸弹 → 枭雄陨落 → 终极对决，奖励 $300–$8000。完成“城市出租”后解锁可重复接取的出租车生意（绿色 `T` 标记）。任务失败会清理本任务生成的载具与 NPC。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动（按镜头方向）/ 驾驶 |
| 点击画面 | 锁定鼠标（启用鼠标转动视角）；菜单界面点击画面还会直接开始游戏 |
| 鼠标（锁定后） | 移动鼠标转动视角，准星固定屏幕中央；未锁定时按两次 mousemove 的相对位移转向，光标停住镜头也停住 |
| 左键 | 射击（自动武器按住连射，半自动武器逐次点击；未锁定时首次点击只用于锁定鼠标，不会走火） |
| 鼠标右键 | 精确瞄准（步行时镜头拉近、肩位加大、FOV 收窄、射击散布降低）；未锁定时也可用右键直接捕获鼠标 |
| Esc | 暂停 / 恢复（暂停会退出鼠标锁定，点击画面也可继续） |
| Shift | 奔跑 |
| R | 换弹 |
| Q / 滚轮 / 1-6 | 切换武器 |
| + / - | 拉近 / 拉远镜头（步行、驾驶通用） |
| E | 上车 / 下车 / 接任务 |
| 空格 | 漂移（手刹） |
| Enter | 开始游戏（菜单界面也可直接点击画面） |

## 文件结构

```
outlawCity/
├── index.html            # 干净的 16:9 舞台与固定脚本加载顺序
├── css/style.css         # 响应式舞台、无扫描线的高清 UI 外框
├── lib/three.min.js      # three.js r128（本地化，未改动）
├── test/run.js           # 零依赖测试（node test/run.js）
└── js/
    ├── render3d.js       # 3D 渲染器（静态世界/实体同步/光照/弹簧臂镜头/粒子/高分屏 resize）
    ├── main.js           # 主循环、世界初始化、输入状态机接入、玩家与载具控制、菜单/暂停/结算
    ├── utils.js          # 数学与随机工具
    ├── config.js         # 世界/玩家/载具/武器/NPC/警察数值
    ├── input.js          # 键盘、鼠标、滚轮、Pointer Lock 与逐帧相对位移
    ├── audio.js          # WebAudio 合成音效
    ├── map.js            # 城市程序化生成、碰撞查询、小地图位图
    ├── entities.js       # Player / Vehicle / NPC / Pickup
    ├── combat.js         # 子弹、粒子、爆炸、命中判定
    ├── ai.js             # 交通 AI / 警察 AI / 护送 AI
    ├── police.js         # 通缉等级、警车编队、下车步战、被捕
    ├── missions.js       # 任务定义与任务状态机
    └── hud.js            # 高清 HUD、程序化小地图、昼夜光照曲线
```

## 提示

- 开局先做“新手上路”任务熟悉驾驶。
- 抢警车会直接涨通缉星（抢来的警车不会再被警察编队收回）。
- 火箭筒适合“终极对决”的卡车车队。
- 夜晚开车记得开前灯（自动亮起），街灯会在你附近自动点亮。

## 已知限制

- 没有存档，刷新页面即重新开局。
- 只有键鼠操作，没有触屏/手柄支持。
- 建筑允许互相重叠，极少数重叠夹缝里碰撞解算会残留一帧抖动（实体每帧都会被推出，不会永久卡死）。
- 出租车生意是目前唯一的可重复内容；剧情任务可重玩，但重复完成不再增加剧情进度。
