# LAB-7 · 声音考古学 — 幽灵频率

> 戴上耳机。你是一名城市音频取证实验室的分析师。
> 午夜零点，一座废弃广播塔每年准时苏醒，向全城发射无人能懂的声音。
> 你将在 **6 段录音** 里，用 **变速 · 倒放 · 滤波 · 频谱图**，破译一座城市沉睡四十年的秘密。

---

## 🎧 这是什么

一款**纯前端、零依赖、双击即玩**的音频取证解谜游戏：

- **6 个连环案件**：雨夜留言 → 倒放的摇篮曲 → 幽灵频谱 → 深夜摩斯 → 无声的尖叫 → 幽灵频率·终局，案件环环相扣，结尾有反转
- **真实音频取证仪器**：变速（0.25×~4×）、倒放、循环、六档滤波（直通 / 低通 / 高通 / 带通 / 陷波 / 峰化）、去噪门、增益放大、波形图 + 实时频谱图
- **程序化合成证据**：每一段"录音"都在你的浏览器里实时合成——雨声、雷声、摇篮曲、摩斯电码、17.5kHz 超声信号、甚至直接画在频谱图里的文字；"随机"层统一走确定性 RNG，同一案件每次合成逐样本一致
- **语音素材真实录制**：关键人声由 Windows 自带 TTS（SAPI）生成，22.05kHz 采样（第一案会降采样为 8kHz 电话音质），内置在代码里，无需联网；解码后仍按 22050Hz 使用，在 44.1/48kHz 设备上语速与音高不变
- **边玩边学**：低通滤波、倒放取证、频谱图读图、摩斯电码、超声频段——每案破译后有「考古笔记」讲解原理
- **实验室玩具**：内置信号发生器（纯音/白噪/摩斯/频谱文字），可以自己造声音、看频谱、练耳朵

## 🔧 技术说明

- **零依赖**：无 npm、无构建、无网络请求；所有素材（含语音 WAV）以 base64 内嵌
- **证据实时合成**：每案打开时在浏览器内程序化合成音频，合成结果按案件缓存，重复进入不重算（6 案全量合成约 116ms）
- **可复现**：噪声、黑胶噼啪等"随机"层统一走 `Synth.rng(seed)` 的 LCG，同一案件两次合成逐样本一致
- **采样率一致**：语音素材用 22050Hz 的 `OfflineAudioContext` 解码，避免 `decodeAudioData` 把数据重采样到设备采样率（48kHz）后仍被当作 22050Hz 使用；`cases.js` 另按真实采样率换算兜底
- **频谱文字**：5×7 位图字体按列映射为不同频率的短音，直接"画"进频谱图（B-7、ECHO）
- **摩斯电码**：标准时序（点 1 单位 / 划 3 单位 / 字母间 3 / 词间 7），4 案 MIDNIGHT、5 案 SOS@17.5kHz、6 案 73
- **增益校准**：按 2.5–6.5s 窗口实测 RMS——滤波前人声比雨声低 2.9dB（能听见但糊），引擎低通 @1kHz 后为 +10.6dB（清晰），雨声残留约 16%
- **频谱/波形坐标**：FFT bin k 的频率是 `k × sr / 1024`，频率→像素行按 Nyquist 映射，因此 0–8kHz / 0–3kHz 放大视图的刻度与实际频率一致
- **列率与帧率解耦**：频谱/波形按采样时钟产列（每秒 90 列），不再"一帧一列"——否则 60Hz 屏上时间轴会整体缩水 1.5 倍
- **超声案件**：44.1kHz 采样合成 17.5kHz 信号，频谱图可见；0.25 倍速播放后降至 4.4kHz 可闻
- **重新生成语音**：修改 `tools/voice-texts.json` 后运行 `tools/generate-voice.ps1`，再把新 WAV 转 base64 更新 `js/voices.js`
