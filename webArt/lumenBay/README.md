# 光湾市 · LUMEN BAY

一座会呼吸的像素海港。清晨、黄昏与夜景共用同一座城市，却拥有三种完全不同的光线、天气、生活节奏与生成式配乐。

全部画面与声音均由浏览器实时生成：没有图片素材、没有音频文件、没有字体依赖，也没有构建步骤。

## 运行

直接双击 `index.html` 即可（支持 `file://`）。也可以在项目目录启动一个静态服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

建议使用最新版 Chrome、Edge、Firefox 或 Safari。首次进入需要一次点击，这是浏览器播放声音所要求的用户手势。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击「进入城市」 | 带声音进入，推荐佩戴耳机 |
| 点击「静音漫游」 | 安静地进入，之后可在右下角开启声音 |
| 数字键 `1` / `2` / `3` | 切换清晨 / 黄昏 / 夜景 |
| `M` | 静音 / 恢复声音 |
| 点击行人 | 向对方打招呼，触发气泡、挥手与一声轻响 |
| 在画面上移动鼠标 | 搅动海风，吹落树叶，让前景的光斑轻轻漂移 |
| 右下角音量滑杆 | 调整音乐音量 |
| `Esc` | 收起提示气泡 |

## 三个时刻

- **清晨 · MORNING TIDE** — 06:18，薄雾、清亮的海面与低低的晨日。木吉他般的拨弦、柔和潮声与第一班渡轮。
- **黄昏 · GOLDEN HOUR** — 18:42，暖橙落日沉入楼群，窗火与彩灯次第亮起。慢速铺底、温暖和声与一条写给海面的旋律。
- **夜景 · AFTERGLOW** — 22:16，月光、霓虹与青色电子脉冲。合成器琶音、低频脉动和更活跃的城市夜生活。

三种调色板共享同一组语义键，切换时会进行约 2.1 秒的颜色与光照过渡，而不是简单换图。

## 画面里有什么

- 前景、中景、远景三层城市纵深，以及镜头虚化光斑。
- 玻璃塔楼、装饰艺术高楼、钟楼、旧屋、仓库、鱼市、旅馆、夜市、咖啡馆与右侧民居。
- 石桥、桥拱、桥灯、海湾、倒影、波纹、渡轮与桥下小船。
- 行道树、花坛、杂草、鸽子、路灯、长椅、自行车、烟囱与晾衣绳。
- 11 位自由漫步的居民和一只狗；相遇时会停下交谈，也可以点击他们打招呼。
- 飘落的树叶、被风带起的尘土、炊烟、节日串灯、霓虹边缘灯管与闪烁招牌。
- 白天与夜晚分别有太阳和月亮，主光源、副光源与长阴影方向随时刻变化。
- 桌面端顶部时间控制台，移动端底部时间控制台；窄屏会自动切换为竖屏构图。

## 项目结构

```
lumenBay/
├── index.html          # 页面结构、HUD、开场与控件
├── css/
│   └── style.css       # 视觉样式、响应式布局、动效降级
└── js/
    ├── palettes.js     # 三套调色板、城市元数据与颜色插值
    ├── audio.js        # Web Audio 生成式配乐、混响与场景切换
    ├── scene.js        # Canvas 2D 城市渲染、天气、人群与交互
    └── app.js          # 应用启动、开场、控件与模式状态
```

## 技术说明

- 场景内部固定为 `960 × 540` 像素，通过 CSS `object-fit: cover` 与 `image-rendering: pixelated` 放大，保持清晰的像素边缘。
- 所有建筑、树木、人物、光影、粒子和界面装饰都由 Canvas 2D 与 CSS 程序化绘制。
- 音频由 Web Audio 实时合成，包含三套编曲、环境声、混响、交叉淡化与音量控制。
- 遵循 `prefers-reduced-motion`：减少镜头闪烁与高动态粒子，但保留城市的基本呼吸。
- 没有第三方库、网络请求或构建产物；整个项目可以离线运行。
