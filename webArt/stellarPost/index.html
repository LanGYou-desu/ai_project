01 — 投递

把一句话，交给星空

不用注册，不留名字。它会被存进这台机器上的一个 JSON 文件，等下一个路过的人读。

还可以写 80 字

同一网络每 12 秒可投递一次；内容是公开的，别写隐私信息。

02 — 星图

已经有 颗星亮着

把鼠标停在星星上（或按 Tab 聚焦），会浮出那句话。

03 — 手记

这个小站是怎么长出来的

没有框架、没有 npm、没有一张图片请求，全部是手写的。

01一片会呼吸的星

星空是 Canvas 逐帧画的：三层景深视差、靠近会被推开的鼠标引力、光标牵出的星座连线，还有偶尔划过的流星。

02每句话都是一颗星

星星的位置由内容 ID 做 djb2 散列得出，服务端 Node 与浏览器 JS 用同一套算法，所以刷新后星星不会乱跑。

03数据就躺在文件夹里

投递内容写进 data/wishes.json，服务端用临时文件 + 原子重命名落盘；data 目录不对外开放，只能通过接口读写。
