# THE VANISHED · 林薇失踪事件 —— 桌面悬疑事件

> 一场**实时上演**的桌面惊悚剧。你在凌晨接班时发现同事林薇失踪，
> 接下来的约 40 分钟里，线索通过 **真实的 Windows 通知**、**真实的磁盘证据文件**
> 和模拟聊天软件陆续送达。错过通知就可能错过线索——结局由你的"在场度"决定。

- 类型：实时桌面悬疑剧（单机 · 真实时间线）
- 技术栈：Node.js（零第三方依赖）+ 原生 HTML/CSS/JS + PowerShell（真实系统通知）
- 时长：约 40 分钟一局（可在界面右上角切换 4x/8x/16x 倍速），5 种结局
- 每次开局世界随机细节相同、但你的注意力不同 → 结局不同，可重开

## 玩法

1. 双击 `start.bat`（或 `node server.js`），浏览器打开调查台，游戏自动开始。
2. **真实 Windows 通知**会直接弹到屏幕右下角——那是线索的一部分。
3. 证据文件会真实写入 `evidence/` 目录，可以随时用资源管理器打开查看。
4. 聊天窗口收到林薇的加密消息（base64），可以自己解码。
5. 三个检查点决定你的"注意力"评分；最终选择 + 注意力 = 5 种结局之一。

## 结局

| 结局 | 条件 | 简述 |
| ---- | ---- | ---- |
| 真相大白 | 注意力 ≥ 11 且行动正确 | 救出林薇，老周落网 |
| 营救成功，真凶在逃 | 注意力 ≥ 8 且行动正确 | 救出林薇，但证据不足 |
| 迟到的救援 | 行动正确但注意力不足，或证据充分却没行动 | 人救出来了，晚了点 |
| 一夜之差 | 注意力不足且行动错误 | 第二天清晨才发现她 |
| 沉默的夜班 | 什么都没做 | 三天后才发现她…… |

## 技术要点

- 时间线引擎：真实时间推进（`accumulatedMs + dt*speed`），事件按剧本投递，存档持久化。
- 真实通知：`notify.ps1` 通过 Windows Toast API（WinRT）弹出系统通知，失败自动回退到消息框。
- 真实证据：`evidence/` 目录中的 7 份文件由服务器按时间线真实生成（txt / csv）。
- 计分：查看证据 +1（上限 7）、检查点答对 +2、最终行动正确 +4。

## 测试

`node test/run.js`：15 项测试（剧情数据完整性 / 时间线投递 / 不重复投递 / 倍速 /
持久化 / 计分 / 5 种结局判定 / 服务器冒烟）。

## 目录结构

```
the-vanished/
├── server.js            # 服务器：时间线运行 + 真实通知 + 证据生成 + API
├── notify.ps1           # 真实 Windows Toast 通知脚本
├── lib/
│   ├── story.js         # 剧情时间线（25 个事件）与 5 种结局
│   ├── engine.js        # 时间线引擎（真实时间 / 计分 / 结局）
│   └── notify.js        # Node → PowerShell 通知桥
├── public/              # 调查台界面（聊天 / 证据 / 案件板）
├── test/run.js          # 测试
├── evidence/            # 运行时生成的真实证据文件（不入库）
├── state.json           # 进度存档（不入库）
└── start.bat
```
