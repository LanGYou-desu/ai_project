# BIKE ART · 骑车 · SVG 动画小画

> 三张**单文件 SVG 动画**小画：没有脚本、没有依赖、没有素材文件——
> 打开 HTML 就是一幅会动的画。主题都关于「骑车」。

## 🖼 作品

| 作品 | 文件 | 说明 |
| --- | --- | --- |
| 海边的鹈鹕 · 骑单车 | [`bike0931/pelican-bike.html`](bike0931/pelican-bike.html) | 一只鹈鹕沿海边骑单车，46 段 SMIL 动画 |
| 骑车的鹈鹕 | [`bike1017/pelican-bike.html`](bike1017/pelican-bike.html) | 同一主题的新版重绘（骑车的鹈鹕） |
| 艾玛骑车 | [`bike1017/emma-bike.html`](bike1017/emma-bike.html) | 小女孩艾玛骑车的清新画风 |

双击 `index.html` 有作品索引页；也可以直接双击上表中的任意文件。

## 🛠 技术

- 纯 `<svg>` + SMIL（`<animate>` / `<animateTransform>`）动画，零 JavaScript、零依赖
- 单文件自带全部样式，离线可用
- `bike0931` / `bike1017` 是两个版次目录（保留作者原始编号）

## 🧪 测试

纯静态美术作品，没有自动化测试。
