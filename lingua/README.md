# LINGUA · 语言演化博物馆

> 造一门语言，看它在一千年里漂移、分裂、长出文字。
> 你为原始部落写下第一批词汇，之后的一切——元音推移、辅音弱化、方言分化、借词、文字诞生——都由演化引擎自己发生。
> 纯前端 · 零依赖 · 双击即玩 · 同一颗种子 100% 可复现

---

## 🏛️ 这是什么

一座**语言演化博物馆**：一门由你命名的虚构语言，在一个虚拟部落里演化 **1000 年**（20 个纪元 × 50 年）。

| 展品 | 说明 |
| --- | --- |
| 🌳 **语系树** | 公元 0→1000 年横向时间轴：洪水/迁徙/海平面上升导致部落**三次分裂**（公元 300 / 600 / 800 年），形成 **7 条分支线**（3 条祖语线继续演化 + 4 个末端方言），各自独立演化 |
| 🗣️ **音变引擎** | **24 条**历史音变规则（元音推移 / 辅音弱化 / 词尾清化 / 颚化 / 换位 / 双元音化 / 浊化同化 / 滑音化……），每 50 年按概率发生 |
| 📖 **现实语言学注释** | 每条音变都附真实语言史参照：英语元音大推移、拉丁语→罗曼语的弱化、德语词尾清化、日语式 umlaut……边玩边学 |
| 🎵 **语言歌谣** | 用当前分支的演化词形拼成 **5 首**歌谣（语序之歌/摇篮曲/数鱼谣…），可试听发音 |
| 🧪 **创作台** | 添加自定义词根、调节音变/语法频率（50%~200%）、亲手制造分裂——一切仍可复现 |
| 🏅 **成就系统** | **8 枚**徽章（初入馆/看见分裂/遇见借词/见证文字/踏遍七脉/馆藏家/造物者/语言学者），解锁即弹 |
| 🗺️ **维基导出** | 一键导出《XX 语言维基》HTML（含语系树截图/编年史/全分支词表） |
| 🔊 **试听发音** | 词表与词源追踪中的词都可试听（元音=正弦音、辅音=噪声脉冲的程序化发音），连点会自动停掉上一段 |
| 🏛️ **音变图鉴** | 24 条音变的全览百科：哪些发生过、涉及哪些分支、次数统计，未发现的可解锁（🔒→📖） |
| 📈 **音系演化曲线** | 词表顶部一条 0→1000 年音位数量曲线，直观看到音系变薄/变厚 |
| 🎴 **语言名片** | 一键生成一句话语言简介（语序/复数/双数/借词/文字…），复制即可分享 |
| 🎲 **随机邂逅** | 词表里随机抽一词并直接展开它的词源追踪 |
| 🔀 **借词落点随机** | **4 波**借词（骑兵/传教士/海商/官府）的目标分支随种子变化（仍可复现），不同平行世界借词侵入不同方言 |
| 📜 **语法演化** | **22 种**语法事件：语序 SVO→SOV→VSO、复数/双数/过去时/属格标记、冠词、被动、传闻标记、名词阴阳、否定、进行体……各有轶事 |
| 🔎 **词源追踪** | 点击任意词弹出词条卡，一路回推 1000 年：每个音变都标注了规则名（*woda → wod → wot → wat → wet → wit），并随游标年代截断 |
| 🧬 **同源词对照** | 同一个词义，看各分支在一千年后各说各话——原始词 *woda 变成 wed / ueda / wor / ear… |
| 🎼 **音系档案** | 从词表自动推导该部族当前的辅音/元音音位集，随时可看音系在变薄还是变厚 |
| 🖋️ **文字诞生** | 公元 500 年文字出现：每个词都有「图画（象形）→ 简化（笔画化）→ 字母化」三阶段字形 |
| 🦴 **甲骨展柜** | 文字展厅里按语义类别整排陈列象形字形，**124 个词全部有专属象形**（无占位纹理） |
| 💾 **导出档案** | 一键导出这门语言的完整 JSON 档案（全部 7 分支词表、语法、大事记、种子、创作台参数） |
| 🏛️ **名语言馆** | 六种预制语言（雾语/霜语/星河语/盐语/铁语/潮语）一键参观，各有性格 |
| 📜 **编年史时间轴** | 语系树下方可点击的编年史：洪水分裂/翻山分裂/北骑借词/文字诞生/海商借词/海升分裂，点击直接跳转年代 |
| 🔍 **词表搜索** | 词表支持按词义或词形搜索，类别以彩色徽章显示（借词按词义自带类别，不再一律显示为「器物」） |
| 🎟️ **馆藏系统** | 收藏你的语言；「分享种子」把同一门语言发给别人，打开即还原 |
| 🛡️ **输入容错** | 被改坏的分享链接、非法种子、极端参数（超大词表/频率/分裂数）都会被校验裁剪，页面不会白屏 |

## 🚀 快速开始

**方式一（推荐）**：双击 `start.bat`，或用 Chrome / Edge 打开 `index.html`。

**方式二**：本地服务器

    python -m http.server 8097   # 然后访问 http://127.0.0.1:8097

**方式三**：跑测试（需要 Node.js，无第三方依赖）

    node test/run.js            # 57 项单元测试
    npm test                    # 等价写法（node --test "test/*.test.js"）
    npm run verify              # 现状核对脚本：打印词表/规则/事件数量并校验不变量

## 🎮 怎么玩

1. 打开页面会自动生成一门语言（右上角可改名 / 重新演化 / 分享种子 / 导出档案）。
2. 拖动**语系树**下方的时间轴，或点 ▶ 播放，看 1000 年里的三次分裂与音变。
3. 点击**分支轨道**选中一个部族，右侧切换展厅：词表（含音系档案）/ 同源词 / 语法 / 大事记 / 文字 / 借词 / 歌谣 / 图鉴 / 创作台。
4. 在词表或同源词里点击任意词 → 弹出**词条卡**，含三阶段字形与词源追踪。

> 💡 同一名字 + 同一颗种子 = 完全相同的演化。换种子，就是另一个平行世界。
>
> 💡 操作：语系树上**按住拖动**可刮擦年代；<kbd>空格</kbd> 播放/暂停，<kbd>←</kbd><kbd>→</kbd> 调年代（<kbd>Shift</kbd> 一次 10 年）；播放有 ×1/×2/×4 速度；词表支持**类别过滤 + 搜索**；同源词展厅内置**双分支对比**（差异高亮）；关闭页面后会自动**记住上次参观的位置**。

## 🔧 技术说明

- **124 个原始词汇**（13 个语义类别）· **24 条音变** · **22 种语法事件** · **4 波借词**（骑兵/传教士/海商/官府）· **8 枚成就** · **5 首歌谣** · **6 种预制语言**。
- 零第三方依赖：引擎为纯 JS，浏览器 + Node 双端运行（UMD 导出），57 项单元测试覆盖确定性、数据完整性、输入健壮性与全分支词形合法性。
- 演化引擎完全由种子驱动（FNV-1a 哈希 + mulberry32 PRNG），结果可复现、可分享；所有查询函数都接受「分支 id + 纪元」，同种子下逐纪元逐分支完全一致。
- 字形系统为程序化生成：124 个词义各有一套手绘象形图元（`glyphs.hasGlyph` 可查），抽象文字由词形哈希驱动；图元按词义/词形缓存复用。
- 同源词查询只读取单个词的词源日志（不再为每个分支重建整张词表），全量 124 词的对照约 0.08ms。
- 输入校验集中在 `world.evolve`：词义剥离危险字符、词形规范化为 `[a-z]+`、类别回落到合法值、频率夹在 0~200%、自定义词根 ≤200 条、手动分裂 ≤12 次；`main.js` 对分享链接参数再做一层规整。
