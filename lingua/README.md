# LINGUA · 语言演化博物馆

> 造一门语言，看它在一千年里漂移、分裂、长出文字。
> 你为原始部落写下第一批词汇，之后的一切——元音推移、辅音弱化、方言分化、借词、文字诞生——都由演化引擎自己发生。
> 纯前端 · 零依赖 · 双击即玩 · 同一颗种子 100% 可复现

---

## 🏛️ 这是什么

一座**语言演化博物馆**：一门由你命名的虚构语言，在一个虚拟部落里演化 **1000 年**（20 个纪元 × 50 年）。

| 展品 | 说明 |
| --- | --- |
| 🌳 **语系树** | 公元 0→1000 年横向时间轴：洪水/迁徙/海平面上升导致部落**三次分裂**，最终形成 **7 个方言分支**，各自独立演化 |
| 🗣️ **音变引擎** | **24 条**历史音变规则（元音推移 / 辅音弱化 / 词尾清化 / 颚化 / 换位 / 双元音化 / 浊化同化 / 滑音化……），每 50 年按概率发生 |
| 📖 **现实语言学注释** | 每条音变都附真实语言史参照：英语元音大推移、拉丁语→罗曼语的弱化、德语词尾清化、日语式 umlaut……边玩边学 |
| 🎵 **语言歌谣** | 用当前分支的演化词形拼成 5 首歌谣（语序之歌/摇篮曲/数鱼谣…），可试听发音 |
| 🧪 **创作台** | 添加自定义词根、调节音变/语法频率（50%~200%）、亲手制造分裂——一切仍可复现 |
| 🏅 **成就系统** | 8 枚徽章（看见分裂/遇见借词/见证文字/踏遍七脉/造物者/语言学者…），解锁即弹 |
| 🗺️ **维基导出** | 一键导出《XX 语言维基》HTML（含语系树截图/编年史/全分支词表） |
| 🔊 **试听发音** | 词表与词源追踪中的词都可试听（元音=正弦音、辅音=噪声脉冲的程序化发音） |
| 🏛️ **音变图鉴** | 24 条音变的全览百科：哪些发生过、涉及哪些分支、次数统计，未发现的可解锁（🔒→📖） |
| 📈 **音系演化曲线** | 词表顶部一条 0→1000 年音位数量曲线，直观看到音系变薄/变厚 |
| 🎴 **语言名片** | 一键生成一句话语言简介（语序/复数/双数/借词/文字…），复制即可分享 |
| 🎲 **随机邂逅** | 词表里随机抽一词并直接展开它的词源追踪 |
| 🔀 **借词落点随机** | 4 波借词的目标分支随种子变化（仍可复现），不同平行世界借词侵入不同方言 |
| 📜 **语法演化** | **14 种**语法事件：语序 SVO→SOV→VSO、复数/双数/过去时/属格标记、冠词、被动、传闻标记、名词阴阳、否定、进行体……各有轶事 |
| 🔎 **词源追踪** | 点击任意词，一路回推 1000 年：每个音变都标注了规则名（*woda → wod → wot → wat → wet → wit） |
| 🧬 **同源词对照** | 同一个词义，看 7 个分支在一千年后各说各话——原始词 *woda 变成 wed / ueda / wor / ear / oad / woro / uara |
| 🎼 **音系档案** | 从词表自动推导该部族当前的辅音/元音音位集，随时可看音系在变薄还是变厚 |
| 🖋️ **文字诞生** | 公元 500 年文字出现：每个词都有「图画（象形）→ 简化（笔画化）→ 字母化」三阶段字形 |
| 🐎 **两波借词** | 北方骑兵带来 马/剑/商人/盐；南来海商带来 茶/帆/珍珠/香料——只进入特定分支，形成同源差异 |
| 💾 **导出档案** | 一键导出这门语言的完整 JSON 档案（全部 7 分支词表、语法、大事记、种子） |
| 🏛️ **名语言馆** | 六种预制语言（雾语/霜语/星河语/盐语/铁语/潮语）一键参观，各有性格 |
| 📜 **编年史时间轴** | 语系树下方可点击的编年史：洪水分裂/翻山分裂/北骑借词/文字诞生/海商借词/海升分裂，点击直接跳转年代 |
| 🦴 **甲骨展柜** | 文字展厅里按语义类别整排陈列象形字形，像真的博物馆展柜 |
| 🔍 **词表搜索** | 词表支持按词义或词形搜索，类别以彩色徽章显示 |
| 🎟️ **馆藏系统** | 收藏你的语言；「分享种子」把同一门语言发给别人，打开即还原 |

## 🚀 快速开始

**方式一（推荐）**：双击 `start.bat`，或用 Chrome / Edge 打开 `index.html`。

**方式二**：本地服务器

    python -m http.server 8097   # 然后访问 http://127.0.0.1:8097

**方式三**：跑测试（需要 Node.js）

    node test/run.js            # 31 项单元测试（或 npm test / npm run verify）

## 🎮 怎么玩

1. 打开页面会自动生成一门语言（右上角可改名 / 重新演化 / 分享种子 / 导出档案）。
2. 拖动**语系树**下方的时间轴，或点 ▶ 播放，看 1000 年里的三次分裂与音变。
3. 点击**分支轨道**选中一个部族，右侧切换展厅：词表（含音系档案）/ 同源词 / 语法 / 大事记 / 文字 / 借词。
4. 在词表或同源词里点击任意词 → 底部展开**词源追踪**，看它从原始词一路变到今天的样子。

> 💡 同一名字 + 同一颗种子 = 完全相同的演化。换种子，就是另一个平行世界。
>
> 💡 操作：语系树上**按住拖动**可刮擦年代；<kbd>空格</kbd> 播放/暂停，<kbd>←</kbd><kbd>→</kbd> 调年代（<kbd>Shift</kbd> 一次 10 年）；播放有 ×1/×2/×4 速度；词表支持**类别过滤 + 搜索**；同源词展厅内置**双分支对比**（差异高亮）；关闭页面后会自动**记住上次参观的位置**。

## 🔧 技术说明

- **124 个原始词汇**（13 个语义类别）· **24 条音变** · **22 种语法事件** · **4 波借词**（骑兵/传教士/海商/官府）。
- 零第三方依赖：引擎为纯 JS，浏览器 + Node 双端运行（UMD 导出），26 项单元测试覆盖确定性、数据完整性、全分支词形合法性。
- 演化引擎完全由种子驱动（FNV-1a 哈希 + mulberry32 PRNG），结果可复现、可分享。
- 字形系统为程序化生成：象形图案按语义类别手绘，抽象文字由词形哈希驱动。
