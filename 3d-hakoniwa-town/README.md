# 🏝 箱庭小镇 · Hakoniwa Town

一个用 **Three.js** 打造的精致 3D 箱庭（微型世界）小镇：漂浮在云海之上的岛屿，
高低错落的台地、丘陵、湖河与海角，白天阳光明媚，夜晚灯火辉煌、烟花绽放。

零运行时依赖：Three.js 已本地化在 `vendor/`，双击 `index.html` 即玩，离线可用。

## ✨ 功能特性

### 昼夜循环
- 太阳/月亮沿天空轨道运行，天空渐变、霞光、星空自动切换
- 晨昏时天空染上橙金色，夜晚升起星星与月亮
- 入夜后：窗户亮灯、路灯点亮、招牌发光、灯塔光束旋转、摩天轮彩灯闪烁、萤火虫飞舞、湖上飘起水灯
- 夜晚随机绽放**烟花**
- 右上角实时时钟 + 时段名称（清晨/正午/黄昏/夜晚…），钟楼四面指针与小镇时间同步
  （时针跟随分钟连续走动：03:30 指向 105°）

### 高低错落的地形（拒绝“小方块堆砌”）
- 中央台地小镇 + 神社丘陵 + 城堡山 + 林丘草丘 + 海角灯塔
- 湖泊与河流蜿蜒入海，溪流从台地边缘流入湖中（动态水带 + 水雾 + 水花）
- 石路是**沿路径逐点采样地形的带状网格**（合并为单个网格），坡地上也始终贴着地面；
  通往神社、城堡、港口都有台阶（台阶底面按四角最高地形落位，不会埋进坡里）

### 丰富场景
- 广场喷泉（粒子水柱）、三间发光招牌店铺（茶屋/花屋/面包房）、钟楼、民居群
- 日式神社 + 鸟居 + 石灯笼 + 樱花树；精工天守阁（宽檐四坡顶 + 上层塔楼 + 角楼垛口）+ 五重塔
- 旋转风车、摩天轮（彩灯 + 始终直立的吊舱）、灯塔、港口码头与停泊帆船
- 数百株花草（实例化渲染）、灌木、岩石、松树/阔叶树/樱花树
- **程序化纹理**：屋瓦、灰泥墙面、石砌、木纹、鹅卵石路面、草地颗粒——全部由代码生成
- 木栅栏（栈道边/观景台）、窗棂百叶、檐口墙角饰线等细节

### 载具与动态元素
- 🚗 彩色小车队沿石路往返行驶（含货车）：车轮滚动、车身贴合坡地、夜间车灯/尾灯亮起
- ✈️ 空中飞艇绕岛巡航：吊舱亮灯（独立材质，不受车灯闪烁影响）、螺旋桨旋转、随风轻摆
- 飘移的云、绕岛飞行的鸟群（扇翅）、沿河往返的小船、散步的村民
  （行人以地面高度为基准叠加步行起伏，不会逐帧累积飘空）
- 炊烟袅袅、旗帜飘动、树木摇曳、喷泉水柱、湖上水灯漂移
- 摩天轮吊舱挂在支架上、每帧按轮盘角度重算位置，因此永远直立；风车、灯塔光束持续运转

## 🚀 运行方式

**方式一（最简单）**：直接双击打开 `index.html`（已内置本地 three.js，无需联网）。

**方式二（推荐，本地服务器）**：

```bash
cd 3d-hakoniwa-town
# 双击 run.bat：有 Node.js 时自动启动本地服务（http://localhost:8080）并打开浏览器；
# 无 Node.js 时回退到 python -m http.server 8080
```

Windows 也可双击 `run.bat` 一键启动。

## ⚡ 性能与实现要点

- **几何体/材质缓存**：`H.boxGeo / cylGeo / coneGeo / sphGeo / circleGeo / planeGeo / torusGeo`
  按尺寸复用几何体，`H.mat()` 按颜色+参数复用材质，接触阴影圆盘也共享几何与材质。
  优化后唯一几何体 **1675 → 663**、唯一材质 **251 → 154**、网格 **1911 → 1745**。
- **道路合并**：原先每段路一个水平方块（171 个网格，坡地上四角最深扎进地形 1.86），
  现在合并为**单个贴地网格**（346 个顶点），顶层场景节点 **512 → 326**。
- **帧循环零分配**：昼夜更新复用临时 `Vector3/Color`，不再逐帧 `new`；
  测试会断言帧循环期间不新增几何体与材质。
- **实例化渲染**：花草、草丛、岩石使用 `InstancedMesh`。
- **实测规模**（`node test/run.js` 同款桩环境）：世界构建约 0.4 秒，
  约 195k 三角形、1745 个网格、326 个顶层节点；每帧 CPU 更新约 0.06 ms（不含 GPU 绘制）。
- **健壮性**：WebGL 不可用或渲染器构造失败时显示提示而不是白屏；
  窗口尺寸为 0（最小化/隐藏）时相机与渲染尺寸兜底；resize 事件合并到一帧内处理；
  页面 `pagehide` 时停止动画循环并调用 `H.disposeCaches()` 释放几何体/材质/贴图缓存。

## 🛠 自定义指南

- **调整地形**：编辑 `js/terrain.js` 中 `H.groundHeight`（台地、山丘、湖河都由函数叠加生成）
- **增减建筑**：编辑 `js/town.js` 的 `H.buildTown`，按 `house(x, z, 朝向, 参数)` 等方式添加
- **换一张地图**：改 `js/util.js` 里的 `H.SEED`（默认 `20260821`），或在控制台调用
  `H.resetRandom(种子)` 后重建；同种子必定生成同一张地图
- **昼夜速度**：编辑 `js/dynamics.js` 中 `H.env.speed` 或直接在 UI 调整
- **白天时长**：`js/dynamics.js` 中 `env.t + dt * env.speed / 60` 的 60 秒 = 一天

## 🧰 技术栈

- Three.js **r158**（本地 vendor，支持离线 `file://` 打开；版本号取自 vendor 内 `REVISION`）
- 纯原生 JS + Canvas 贴图（无外部资源依赖，无构建步骤）
- WebGL 着色器：天空渐变、动态水面、瀑布水幕
- 实例化渲染（花草、岩石）与几何/材质缓存保证性能
