# 无光之城 UNLIT · 盲者体验馆

> **戴上耳机。屏幕几乎全黑。你是一个三个月前失去视力的人，今天是你重学日常的第一天。**
>
> 这不是恐怖游戏，而是一趟**走进视障者世界**的共情之旅：用白杖回声"看"路、用耳朵听信号灯过马路、
> 摸盲文读妈妈的信、摸钱币结账、听水开的声音做饭——原来看不见，也可以完整地生活。

纯前端零依赖（原生 HTML/CSS/JS + Web Audio 程序化合成，无任何外部素材/库），一次完整通关约 30–60 分钟。

## 🎧 怎么玩

```powershell
.\start.bat                  # 打开 index.html（建议 Chrome / Edge，务必戴耳机）
node test\run.js             # 80 项单元测试（含脚本化全流程通关）
node test\smoke-browser.js   # 43 项浏览器冒烟测试（stub DOM 驱动真实帧循环）
```

也可以直接双击 `index.html`——没有构建步骤，没有依赖。

### 操作

| 按键 | 作用 |
| ---- | ---- |
| W / ↑ · S / ↓ | 前进 / 后退 |
| ← →（或 A / D） | 原地转身 |
| Space | 敲白杖，听回声（返回距离 + 左/右方位） |
| E | 触摸 / 互动 / 推进对话 / 试音击拍 |
| M | 心灵地图（自己绘制记忆） |
| H | 提示 · N 语音导航 · F 知识卡图鉴 |
| Tab | 沉浸 ⇄ 辅助模式（默认**沉浸**；覆盖层打开时 Tab 用于移动焦点） |
| Esc | 关闭谜题 / 知识卡（试音会暂停，可再找老板重来） |
| Enter | 推进对话 · 提交盲文答案 · 地图上放置标记 |
| Backspace | 地图上删除光标处的标记 |
| 1…9 · ← → | 谜题内：选第 N 个选项 / 移动焦点（数字键选选项后按 Enter 确认） |

**沉浸模式（默认）**：画面几乎全黑，一切靠听（立体声方位、距离音量、距离低通滤波、白杖回声）。
**辅助模式**：显示微弱轮廓与目标高亮，方便上手；标题屏按钮或游戏中 Tab 随时切换。

## 🧩 玩法系统

- **听觉场景**：声源按「世界坐标 → 方位角 → 立体声像 / 距离音量 / 距离低通滤波」逐帧计算（纯函数，可测试）。
  一个货架在地图上是多格，取**离玩家最近的那一格**定音色与方位；没有 StereoPannerNode 的浏览器自动回退到等功率双声道增益。
- **白杖回声定位**：敲击沿面向锥体（半角 26°、探测 5.5 格）射线检测墙与障碍物，返回距离 / 方位 / 开放度；
  墙距用「粗步进 + 二分细化」精确到厘米级，回声延迟按声速 340 m/s 计算。
- **过街仿真**：信号红绿循环（红灯 5s / 绿灯 8s），红灯车流；绿灯时**已进入路口的车继续驶离、未到停止线的车停下等待**，
  已通过路口的车不会被拉回；被撞会推回最近的安全行。
- **心灵地图**：画布空白，玩家亲手放置「我/门/物/声/险」标记——地图是你自己的记忆（键盘光标 + Enter，或鼠标点击）。
- **触觉谜题**：盲文数字按钮（呼梯/楼层）、盲文信（**磨损单元格**——缺角画成虚线点，可逐格"摸"读）、
  钱币识别（大小/边缘/盲文角标，选中时播放硬币或纸币的声音）、试音（**4 拍节拍器**，命中 ≥3 拍通过）。
- **语音导航**：按 N，系统告诉你**最近**的那个目标在哪个方向、大概多远——就像一位耐心的导盲人。
- **全程语音**：所有旁白、对话、物品描述用中文语音朗读（speechSynthesis，可关闭），并带说话人前缀；无语音环境自动退化为文字。
- **进度存档**：自动保存到 localStorage（每 4 秒 + 每次关键事件），标题屏可「继续上次」；存档损坏或版本不符会被安全忽略。

## ♿ 无障碍设计

这个项目把"无障碍"当作主题，也当作对自己的要求：

- **全键盘可完成**：包括全部谜题——数字键选选项、←→ 移动焦点、Enter 确认、Esc 退出；
  盲文单元格可 Tab 聚焦并按 Enter"摸"读；盲文信输入框按 Enter 提交。**不需要鼠标也能通关。**
- **ARIA**：覆盖层带 `role="dialog"` / `aria-modal`；播报区与 toast 是 `aria-live="polite"`；
  按钮带可读名称（"1. 上排凸点 ▲"）、`aria-pressed` 状态；画布标记为 `aria-hidden`（所有信息都能听到）。
- **焦点管理**：打开谜题 / 知识卡 / 地图 / 引言时自动聚焦到第一个可操作元素。
- **不做键盘陷阱**：有覆盖层时把 Tab 让给浏览器；只有在游戏中才用 Tab 切换沉浸/辅助。
- **音频降级**：浏览器不支持 Web Audio 或自动播放被拦截时，会提示并以纯文字模式继续（游戏仍可通关）。

## ⚙️ 设计说明

- **零依赖**：无第三方库、无音频/图片素材——所有声音（环境底噪、闹钟、钥匙、车流、信号音、硬币与纸币、
  砧板落刀、水开、油锅、节拍器、章节小调）均由 Web Audio 实时合成。
  每种物品有自己的音色（闹钟 940Hz 方波、米袋 620Hz 带通噪声、罐头 2.1kHz 三角波……），越远越闷。
- **节点不泄漏**：一次性音源播完即 `disconnect()`；白噪声缓冲只生成一次并随机取起点复用；
  离开范围的声源池会 `stop()` 并断开全部节点。
- **可测试**：核心逻辑（盲文、声学数学、回声、钱币、世界数据、引擎、过街、谜题、存档、全流程）全部抽为纯函数，
  80 项单元测试 + 43 项浏览器冒烟测试保证游戏"必定可通关"。

## 🔧 近期修复与优化

- **过街判定**：绿灯时已过路口的车不再被瞬移回停止线、也不再冻结在路口边缘；未到停止线的车正常等待。
- **试音**：补上**缺失的节拍器声音**（此前只有视觉圆点，纯听觉玩家无从下手）；第一拍前留 0.9s 准备时间；
  Escape 退出不再被"自动弹回"。
- **音频**：对象声源此前全部被当成同一个低通噪声（滤波类型/频率被忽略），现在按种类合成并接入距离低通；
  修复节点泄漏、每次敲击新建噪声缓冲、无 StereoPanner 时丢失方位等问题。
- **盲文信**：`wear` 数据与 `.dot.worn` 样式此前从未生效，现在真的会磨损（同种子可复现）。
- **语音导航**：指向最近的同名目标（街口两个提示器不再"指反"）。
- **死内容**：收银员的支付提示、老板的台词此前永远触发不到，现已接上。
- **无障碍**：谜题此前**只能鼠标点**（Tab 被全局吞掉），现在全键盘可完成，并补齐 ARIA / 焦点管理。
- **性能**：HUD 与心灵地图不再每帧重写 DOM / 重绘画布，沉浸模式渐变按尺寸缓存。
- **健壮性**：Web Audio 不可用或自动播放被拦截时优雅降级；帧内异常不再被静默吞掉；新增进度存档。

## 已知限制

- 语音朗读依赖系统中文 TTS，音色因平台而异；关掉语音后所有文字仍显示在 HUD 上。
- 钱币的面额/触觉特征为**教学化抽象**（真实人民币版本较多，细节以官方为准）。
- 地图与仿真为游戏化简化（1 格 ≈ 1 米），不构成任何真实出行指导。
