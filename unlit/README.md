# 无光之城 UNLIT · 盲者体验馆

> **戴上耳机。屏幕几乎全黑。你是一个三个月前失去视力的人，今天是你重学日常的第一天。**
>
> 这不是恐怖游戏，而是一趟**走进视障者世界**的共情之旅：用白杖回声"看"路、用耳朵听信号灯过马路、
> 摸盲文读妈妈的信、摸钱币结账、听水开的声音做饭——原来看不见，也可以完整地生活。

纯前端零依赖（原生 HTML/CSS/JS + Web Audio 程序化合成，无任何外部素材/库），约 40–60 分钟通关。

## 🎧 怎么玩

```powershell
.\start.bat          # 打开 index.html（建议 Chrome / Edge，务必戴耳机）
node test\run.js     # 59 项单元测试（含脚本化全流程通关）
node test\smoke-browser.js  # 浏览器脚本冒烟测试
```

### 操作
| 按键 | 作用 |
| ---- | ---- |
| W / ↑ · S / ↓ | 前进 / 后退 |
| ← →（或 A / D） | 原地转身 |
| Space | 敲白杖，听回声探路 |
| E | 触摸 / 互动 / 推进对话 / 试音击拍 |
| M | 心灵地图（自己绘制记忆） |
| H | 提示 · N 语音导航 · F 知识卡图鉴 |
| Tab | 沉浸 ⇄ 辅助模式（辅助显示微弱轮廓） |

**沉浸模式**：画面几乎全黑，一切靠听（立体声方位、距离音量、低通滤波、白杖回声）。
**辅助模式**：显示微弱轮廓与目标高亮，方便上手；随时切换。

## 🧩 玩法系统

- **听觉场景**：声源按「世界坐标 → 方位角 → 立体声像 / 距离音量 / 低通滤波」逐帧计算（纯函数，可测试）。
- **白杖回声定位**：敲击沿面向锥体射线检测墙与障碍物，返回距离 / 方位 / 开放度，回声延迟≈距离/声速。
- **过街仿真**：信号红绿循环（红灯 5s / 绿灯 8s），车辆红灯行驶、绿灯在停车线前刹停；被撞会推回人行道。
- **心灵地图**：画布空白，玩家亲手放置「我/门/物/声/险」标记——地图是你自己的记忆。
- **触觉谜题**：盲文数字按钮（呼梯/楼层）、盲文信（磨损单元格 + 对照表）、钱币识别（大小/边缘/盲文角标）。
- **语音导航**：按 N，系统告诉你当前目标在哪个方向、大概多远——就像一位耐心的导盲人。
- **全程语音**：所有旁白、对话、物品描述用中文语音朗读（speechSynthesis，可关闭），无语音环境自动退化为文字。

## ⚙️ 设计说明

- **零依赖**：无第三方库、无音频/图片素材——所有声音（环境底噪、闹钟、车流、信号音、硬币、水开、切菜、章节小调）均由 Web Audio 实时合成。
- **可测试**：核心逻辑（盲文、声学数学、回声、钱币、世界数据、引擎、过街、谜题、全流程）全部抽为纯函数，59 项测试保证游戏"必定可通关"。
- **无障碍即主题**：游戏本身键盘全支持、可调辅助轮廓、可关语音——我们做的正是"为所有人设计"。
