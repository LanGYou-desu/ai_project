# NETIME · 网络时光机 — 旧互联网考古

> 一台虚构的「网络时光机」：你沿着一个叫 **顾言** 的程序员在五个年代留下的足迹，
> 从 1995 年的 BBS 一路逛到 2025 年的档案馆，收集四枚时间密钥（**网·络·之·声**），
> 破解他留给互联网的最后一个谜题。
>
> **纯前端 · 零依赖 · 双击即玩**。所有网站都是虚构的，但每一处细节都还原了那个年代的质感。

## 🚀 快速开始

**方式一（推荐）**：双击 `start.bat`，选 1 用 Chrome / Edge 打开 `index.html`。

**方式二**：直接双击 `index.html`（纯前端，无服务器、无依赖）。

**方式三**：本地起个静态服务器也行
```bash
python -m http.server 8098   # 然后访问 http://127.0.0.1:8098
```

> 💡 建议使用 Chrome / Edge。进度自动保存在 localStorage。

## 🔧 技术说明

- **零依赖**：全部逻辑为原生 JavaScript + HTML/CSS，可在 `file://` 协议下直接运行。
- **双环境设计**：核心模块（tools / story / sites / engine / puzzle）采用 UMD 式 IIFE，
  浏览器挂到 `window`、Node 走 `module.exports`，因此同一份代码既能跑页面也能被测试直接 require。
- **搜索引擎**：每年代维护关键词索引，隐藏页不出现在结果中，保证谜题不被搜索剧透。
- **链接完整性测试**：自动扫描全部页面 HTML 的 `href`，确保没有死链、隐藏页不被链接。
- **headless 通关测试**：story.test.js 按玩家路径真实解出全部谜题并断言成就，防止剧情改崩。
- **存档**：localStorage（key：`netime-save-v1`），含版本号，可向前兼容合并。

## 🎭 剧情解读（剧透预警）

**他为什么播三十年？**

1995 年最后一期节目里，顾言说了一句没人信的话：**"互联网会把一切都记住。"**
当时有人笑他——声音是世界上最留不住的东西，播完就没了。

他不信。他把网络之声搬进一台 486，把每个字节留在硬盘里，把广播一直开着。
**不是为了给谁听，是为了证明：被发射出去的声音永远不会消失，它只是在等。**

等一个像你这样的人，顺着旧链接、旧密文和源代码里的注释，一路找到这里。

**SIGMA-7 是谁？**

1993 年，他是顾言的第一位听众，写过第一封听众来信。1995 年告别帖下，
他留言「十年后见」，然后搬去了很远的地方。顾言广播三十年，
有一半——是怕他回来的时候，找不到自己。

**四把钥匙的意义**

钥匙不是关卡，是留言。2005 年博客里写着："条条大路通罗马，
而我选择把钥匙放在留言里。" 顾言想确认：一个愿意花三十年，
把散落在五个年代的碎片拼起来的人，才配听见那个信号。

**主题**

互联网是有记忆的——"一切都不会真正消失，只会被埋得更深"；
"有些网站从未真正下线，只是不再被访问"。
网络之声 · 永存 —— 1995 — ∞
