# LASTBROADCAST · 最后的广播

> 末日前的最后 24 小时，你是一座城市里唯一还在播音的公共电台值班员。
> 选播什么歌、说什么话、接谁的电话、要不要回应那个神秘的频率——
> 你每一次开口，都在改变这座城市和十五个具体的人。
> 纯前端 · 零依赖 · 双击即玩 · 多结局叙事模拟

---

## 📻 这是什么

一款**末日电台值班员叙事模拟**：城市被隔离的第七天，站长把钥匙留给你，只说了一句「播到天亮」。

| 系统 | 说明 |
| --- | --- |
| ⏰ **24 小时时间轴** | 12 个回合（每 2 小时一幕），每回合一个决定：播放歌曲 / 新闻播报 / 接听来电 / 回应信号 / 沉默 |
| 🎵 **31 首歌曲** | 每首都有情感标签（安抚/激昂/悲伤/摇篮曲/怀旧/希望/温情/告别），真实影响听众心情——全部由 Web Audio 程序化合成立刻播放；其中 4 首是**特定回合限定曲**，1 首《纪念日》为**隐藏曲**（集齐 6 结局解锁） |
| 👥 **15 位听众** | 守夜人老周、八岁的小雨、被困隧道的阿凯、天文台教授、孕妈妈阿芸、便利店小杨、老听众阿婆、音乐老师罗老师……每个人都有自己的故事与命运 |
| 📞 **电话总机与点歌联动** | 14 通来电，其中 7 通会**点播歌曲**——接听后下一回合放对歌，对方会得到额外加成（「她等到了那首歌」）；T3/T6/T9/T10 是**双来电回合**，只能接一个，另一个会留下错过剧情 |
| 📡 **神秘信号** | 军队强行切频、FREQUENCY X 在倒数——回应与否，通往不同的结局 |
| 🫀 **你的精力条** | 播音、接电话、回应信号都会消耗你；沉默能恢复。精力跌破 25 时你会差点睡着——结局档案里会留下痕迹 |
| 📈 **示波器与 VU 表** | 实时波形示波器 + VU 电平表，收音机质感拉满 |
| 👁 **城市观察与意外插曲** | 每回合一段窗外旁白 + 一条意外插曲（每回合 3 个变体随机），城市以自己的方式活着 |
| 🎧 **环境音层** | 每回合的氛围声随剧情切换：深夜的风、封锁期的警报、停电后的雨、终局的静默心跳 |
| 🏙️ **城市窗口** | 天际线灯火随城市希望起伏，极光/闪电/飘落的灰烬/闪烁的窗（动画），情绪曲线带渐变填充与脉冲点 |
| 🎬 **九种结局** | 黎明歌谣 / 信号·真相抵达 / 火光·陪伴 / 尘埃·沉默 / 不灭的电波 / 黎明之后 / **纪念日**（隐藏）/ **夜莺** / **灯塔**——终局可**写下你最后的话**，附「结局图鉴」解锁统计（0/9→9/9） |
| 📜 **城市档案** | 结局页会根据你的表现生成几句「这座城市记住了什么」的碑文式记录 |
| 📋 **广播日志与听众档案** | 完整播音记录（可**下载为 .txt**）+ 每位听众的最终命运 + **听众支线** + 结局页**本局要点**摘要（接了几通电话/沉默几次/点播达成…） |

## 🚀 快速开始

**方式一（推荐）**：双击 `start.bat`，或用 Chrome / Edge 打开 `index.html`。

**方式二**：本地服务器

    python -m http.server 8096   # 然后访问 http://127.0.0.1:8096

**方式三**：跑测试（需要 Node.js）

    node test/run.js            # 15 项单元测试

## 🎮 怎么玩

1. 每回合先读「播控台」旁白与「城市观察」，再看电话总机谁在等你（注意点播提示）。
2. 在「播放歌曲 / 新闻播报 / 接听来电 / 回应信号 / 沉默」中做一个选择。
3. 接到来电后如果有点播，下一回合放那首歌会有额外加成；双来电回合二选一，另一个会错过。
4. 关键节点：第 6 回合军队切频、第 10 回合 FREQUENCY X、第 11 回合老周/老兵来电、最后是终局发言。
5. 24 小时后迎来结局——附上每一位听众的命运与「城市档案」。

> 💡 想解锁「信号」结局：接温教授电话 → 解码 FREQUENCY X → 终局选「真相」。
> 💡 想解锁「不灭的电波」：全程别沉默，把希望推到 75 以上，终局选「希望」。
> 💡 隐藏结局「纪念日」：先集齐 6 个基础结局，再完整播出一夜（别选沉默）。
> 💡 「夜莺」：接小雨和双胞胎的电话 + 摇篮曲 + 终局「陪伴」；「灯塔」：解码 FREQUENCY X 但别放摇篮曲 + 终局「希望」。
>
> 💡 细节：音量可调（自动记忆）；播音时广播天线红灯闪烁、控制台显示「正在播放」；有未满足的点播请求时会有提示；结局页会显示「第 N 夜」+ **各结局条件达成路线图**；进度自动存档可「继续上局」；可收藏歌曲（播放 +1 希望）；有**成就系统**与**世界观考据**；意外插曲每局随机变化。
>
> 💡 跑测试：`node test/run.js`（26 项）或 `npm test` / `npm run verify`。
> 💡 耳机体验更佳：**31 首歌都是原创曲谱**（旋律/和弦进行/低音/鼓点/音色/速度各自不同），由 Web Audio 合成器实时演奏——小星星变奏曲是《小星星》、军队进行曲有军鼓点、终局圆舞曲是钟琴长音……每首都值得一听。

## 🔧 技术说明

- 零第三方依赖；仿真引擎为纯 JS（浏览器 + Node 双端），26 项单元测试覆盖九种结局的可达性、点歌联动、未接来电、精力条、确定性。
- 引擎无随机、完全确定：同一份剧本必然得到同一结局，便于测试与复盘。
- 音乐为 Web Audio **音序器**实时演奏：每首歌一份曲谱（scores.js：bpm / 四小节和弦进行 / 16 拍旋律 / 音色 piano·bell·lead·pad / 鼓点 soft·none），lookahead 调度循环 64 个 16 分音符；测试校验全部 31 首曲谱合法。
