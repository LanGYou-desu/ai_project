# DESKTOP SIEGE · 桌面保卫战

> 一个**从你电脑的真实数据里长出敌人**的桌面防御射击游戏：启动时游戏会扫描你
> 的用户目录（桌面 / 文档 / 下载 / 图片…）和系统进程，把**真实文件名**变成敌人——
> 你下载过的 `crackme.exe`、写过的 `毕业论文终版.docx`、跑着的 `svchost`……
> 每台电脑的战场都独一无二。你的"家园"就是你的桌面。

- 类型：俯视双摇杆防御射击（Canvas 动作游戏）
- 技术栈：Node.js（零第三方依赖）+ 原生 Canvas / Web Audio
- 时长：20 波 + 4 个 Boss + 无尽模式，一局约 20–40 分钟，可反复挑战
- 敌人全部以真实文件名 + 扩展名行为生成（exe 冲锋、pdf 重甲、zip 分裂、jpg 治疗…）
- 只读取**文件名 / 扩展名 / 大小 / 所属目录**，从不读取文件内容，也不联网上传

## 玩法

- WASD / 方向键移动，鼠标瞄准，按住左键射击。
- 击杀敌人得分并累积连击（连击最高按 ×2 计分，3 秒不击杀清零）；每清空一波额外获得 `100 + 波数 × 25` 分。
- 敌人掉落 **6 种道具**：极速（射速 ×1.8，6 秒）/ 散射（三连发，6 秒）/ 护盾（+45）/ 修复（+35 HP）/ 冻结（全场减速 55%，4 秒）/ 穿透（可穿过 2 个敌人，5 秒）。
- **Boss 出现在第 5 / 10 / 15 / 20 波**，分别取自下载 / 文档 / 图片 / 系统主题里你磁盘上最大的文件；Boss 会发射五向弹幕，血量随波次成长。
- 20 波后进入无尽模式：第 21 波起敌人按波次继续增强，**每 3 轮一个 Boss**（第 22 / 25 / 28… 波）。
- 每波之间有横幅提示，Boss 波横幅会显示 Boss 的真实文件名。

## 快速开始

```bat
start.bat
```

或 `node server.js`，浏览器打开 http://127.0.0.1:8769。首次启动会扫描磁盘
（数百到数千个真实文件），之后启动会优先复用 `scan-cache.json`（默认 6 小时内有效），
点游戏界面外的 `POST /api/rescan` 可强制重新扫描。

| 环境变量 / 参数 | 作用 |
| --------------- | ---- |
| `PORT=8769` | 监听端口（默认 8769，只绑定 `127.0.0.1`） |
| `DS_SEED=20810719` | 波次随机种子（会下发给浏览器，保证前后端一致） |
| `DS_CACHE_TTL_MS=21600000` | 缓存有效期；`0` = 永不过期，负数 = 禁用缓存 |
| `DS_FRESH=1` / `--fresh` | 忽略缓存，启动时强制重新扫描 |
| `NO_BROWSER=1` / `--no-browser` | 不自动打开浏览器 |

## 敌人类别（由扩展名决定）

| 类别 | 扩展名 | 行为 |
| ---- | ------ | ---- |
| 炮灰 fodder | txt / doc / docx / log / md / json / csv / ini / xls / ppt | 慢速小怪 |
| 冲锋者 rusher | exe / msi / scr / bat / cmd / lnk | 高速直冲（速度 ×1.35） |
| 重甲 tank | pdf / zip / rar / 7z / iso | 高血量慢速 |
| 分裂者 splitter | tar / gz / apk | 死后裂成 3 个碎片（碎片血量随波次成长） |
| 虫群 swarm | dll / sys / tmp / dat / bin | 成群小怪 |
| 治疗者 healer | jpg / png / gif / bmp / webp / mp4 / mp3 / wav / avi | 每 1 秒治疗最近的受伤同伴 10 HP；玩家靠近时后撤 |
| BOSS | 该主题下你磁盘上最大的文件 | 五向弹幕 + 高血量（基础 1500 HP，随波次放大） |

扩展名与类别的映射是**唯一**的（一个扩展名只属于一个类别），敌人的实际类别由波次构成决定，
文件名只用来取名——所以每波的实际构成与波次规格完全一致。

## 波次构成

- 第 n 波（1 起）：炮灰 `round(4 + 1.4(n+1))`、冲锋者 `round(1 + 0.7(n+1))`、重甲 `round(0.35(n+1))`、
  虫群 `round(0.6(n+1))`、分裂者 `round(0.3(n+1))`、治疗者（第 5 波起）`round(0.2(n+1))`，
  Boss 波额外 +1（实际数量：第 1 波 8 个 → 第 20 波 77 个）。
- 主题按 `documents → pictures → processes → mixed → system → downloads` 循环（从第 1 波开始）；
  Boss 波的主题与 Boss 主题保持一致。
- 敌人血量随波次 ×`1+0.14(n-1)`，速度 ×`1+0.02(n-1)`。

## 目录结构

```
desktop-siege/
├── server.js            # HTTP 服务器：磁盘扫描 + 波次 API + 静态资源
├── lib/
│   ├── scanner.js       # 真实磁盘 / 进程扫描（边界校验 + 缓存读写）
│   ├── waves.js         # 20 波 + 无尽波次生成（确定性）
│   ├── engine.js        # 纯逻辑游戏引擎（Node + 浏览器双模式 UMD）
│   └── rng.js           # 种子随机数（mulberry32）
├── public/              # Canvas 游戏界面（index.html / style.css / game.js）
├── test/run.js          # 测试
├── scan-cache.json      # 扫描缓存（已加入 .gitignore，不入库）
└── start.bat
```

## HTTP 接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET | `/api/scan` | 扫描摘要（文件数、进程数、Top 目录、最大文件、样例名字） |
| GET | `/api/waves` | 20 波敌人名单 + 扫描摘要 + `seed` + 竞技场尺寸 |
| POST | `/api/rescan` | 强制重新扫描磁盘并重建波次 |
| GET | `/`、`/index.html`、`/style.css`、`/game.js` | 静态资源（仅 `public/` 之内） |
| GET | `/lib/rng.js`、`/lib/engine.js`、`/lib/waves.js` | 白名单脚本，供浏览器直接加载 |

## 安全与边界

- **扫描范围**：只扫描 `USERPROFILE`（或 `HOME`，再退回 `os.homedir()`）下的
  `Desktop / Documents / Downloads / Pictures / Music / Videos`。
  目录必须是绝对路径、真实目录且位于用户主目录之内；拿不到主目录时**拒绝扫描**而不是回退到相对路径。
- **不跟随符号链接**：扫描与静态资源解析都会做真实路径校验，符号链接 / 目录联接无法把读取范围引出边界。
- **不读内容**：扫描只取文件名、扩展名、大小、所属目录；文件名会被清洗（去掉非法字符、零宽字符、前导点，最长 26 字符）。
- **静态服务**：路径先规范化再校验，`..` 穿越与 `public/` 之外的符号链接一律 404；`/lib/` 只放行三个白名单脚本。
- **请求体上限**：所有请求体限制 64 KiB，超限直接返回 `413` 并断开连接。
- **只监听本机**：服务器绑定 `127.0.0.1`，并设置 `X-Content-Type-Options: nosniff`。

## 性能

- 启动优先读 `scan-cache.json`（结构校验 + 时效校验），命中缓存时不再遍历磁盘。
- 扫描按 `cap`（默认 3000）截断，跳过 `node_modules`、`AppData`、`.git`、`Windows` 等目录。
- 波次与敌人名单在服务器端生成一次，浏览器只做渲染与输入，不重复计算。
